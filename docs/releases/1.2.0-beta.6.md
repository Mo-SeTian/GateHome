# GateHome 1.2.0-beta.6

- **策略组与自定义规则支持配置文件（YAML）编辑**：「策略组与节点」「自定义分流」页新增「YAML 编辑」，以 Mihomo 配置文件格式（`proxy-groups:` / `rules:`）查看与修改；页面表单与 YAML 读写同一份配置，任何一侧修改都会实时反映到另一侧，保存前先校验（类型、正则、CIDR、重名与合并结果）。
- **合并优先级**：自定义策略组在合并机场配置时覆盖同名机场策略组，自定义规则始终置于机场订阅规则之前（优先级更高），自上而下依次生效；规则可用 `{rule, enabled, comment}` 表示停用与备注。
- **修复「配置文件」编辑器无法展开、高度被压缩**：全局文本域样式的 `height: auto !important` 覆盖了编辑器高度，现已修正并恢复桌面、移动端与全屏的展开尺寸。

可在管理台「更新」页面选择「Beta 测试版」检查更新。
