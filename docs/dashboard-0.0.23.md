# 可配置概览与服务地址

概览右上角“配置组件”选择显示内容、流量网卡和地图汇聚省份。显隐、顺序、网卡、省份属于服务器配置，保存在 `config/state.json` 并随加密备份恢复；旧配置默认显示全部组件。拖动手柄时显示目标框，松手后保存；取消、无效目标或保存失败不改变已保存顺序。手柄方向键和上移/下移按钮提供另一条操作路径。手机使用独立手柄，正文仍可滚动；减少动态效果设置停止地图线条动画。

CPU 是运行环境整体平均使用率，首次采样等待下一次 5 秒刷新。内存从总量中减去 Linux `MemAvailable`，旧内核使用空闲、缓存、缓冲区估算。Docker 的 `/proc` 可能包含宿主机指标，界面明确此口径，不将它误标为容器限额。存储为各持久化目录所在文件系统的总空间、已用和可用空间，同一文件系统显示相同数值正常。采集失败显示不可用，不伪造为零占用。

网卡 TX 为上传、RX 为下载；累计数据量从网卡启动起计数，包含这张网卡全部流量。速率是两次采样的字节差值除以间隔秒数。自动模式选择累计流量最多的非回环网卡，可手动固定指定网卡，避免多网卡及桥接计数重复累加。计数重置后先重新采样，不显示负速率。

访问/拦截大数字为本次 GateHome 启动计数。趋势、独立 IP、省份分析和地图使用最近 24 小时仍在最近 5000 条缓存内的日志，因此不能等同于全部磁盘历史统计。地图保留最近 20 次访问，省份点使用省会附近示意坐标；默认汇聚点为示意点，或选择服务器所在省份。内网、保留地址、境外及未知来源列入“其他 / 未定位”，不伪造中国省份。可点击“统计”及独立日志页进行详细查询。

地图底图取自 Natural Earth 的公开领域矢量，提取中国大陆、海南、台湾轮廓后投影为轻量 SVG，用于访问方向示意。来源：[Natural Earth 数据](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson)，[使用条款](https://www.naturalearthdata.com/about/terms-of-use/)。SVG 和离线 IP 数据库打包进程序，运行时不请求外部地图服务。

反代“服务地址”第一行打开内网 URL，第二行打开域名和反代组端口。HTTPS 规则选择 HTTPS 端口，普通规则选择 HTTP（HTTP 关闭时选择 HTTPS）；目标协议端口关闭时显示提示，不生成错误链接。只允许 HTTP/HTTPS，无凭据 URL；链接使用 `noopener noreferrer`。此链接按配置端口生成，无法自动获知路由器将外部端口映射为不同端口的情况。

验证命令：

```sh
go test -race ./...
go vet ./...
node scripts/dashboard_checks.mjs
node scripts/security_checks.mjs
node scripts/frontend_checks.mjs
node scripts/motion_checks.mjs
```

定向测试包括：系统计数解析、访客去重与时间范围、配置持久化/备份、全部 API 鉴权、危险 URL 拒绝、双行链接、安全转义、排序边界、取消/失败保存、刷新和退出后的旧请求丢弃。界面检查使用隔离的本机预览及明确的测试访问记录，不读取生产凭据，不代表真实业务访问数据。
