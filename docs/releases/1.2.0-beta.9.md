# GateHome 1.2.0-beta.9

- **修复代理分流「自定义分流」移动端搜索框重叠与 PC 视图切换条左跳**：为 `.filter-inputs` 设置合理的弹性基础宽度与移动端全宽布局，防止搜索框与目标筛选框在窄屏被压扁并与按钮组重叠；同时为工具栏右侧操作条增加 `margin-left: auto`，切换至「规则集」或「YAML 编辑」时操作按钮位置保持稳定不跳动。
- **修复「连接」页卡片内部控件间距紧贴**：将 `SpotlightCard` 内部 `.card-inner` 改为显式 Grid 布局并恢复行间 `12px`/`8px` 间距，标题行、活跃/已关闭切换条与筛选栏层次分明。
- **优化「运行日志」与「配置文件」PC 及移动端工具栏排版**：修复 PC 端运行日志筛选输入框折行导致右侧开关悬空、移动端输入框未铺满的问题；优化配置文件工具栏按钮右对齐，并将移动端三模式切换条排版为等宽三列。
- **优化移动端「专线 DNS 策略」标题栏与窄屏「通知中心」筛选栏对齐**：确保标题栏右侧操作按钮对齐一致，避免窄屏下筛选栏被过度挤压。

可在管理台「更新」页面选择「Beta 测试版」检查更新。
