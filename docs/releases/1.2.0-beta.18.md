# GateHome 1.2.0-beta.18

- **Mihomo 新增外部管理 API 端口与管理密钥配置**：
  - 在「代理分流 → 端口与核心」新增外部管理 API 配置区，支持自定义 `external-controller` 管理端口（可配置为 `9090` 或其他未冲突端口）及可选开启「允许局域网 / Docker 访问管理端口 (`0.0.0.0`)」，方便 `neko-master` 等第三方服务直接接入；默认保持仅监听 `127.0.0.1` 回环地址。
  - 新增管理密钥（`secret` / Token）查看、修改与一键随机生成能力；密钥通过 `/api/credentials/reveal` 结合管理员会话与二次验证按需查看，接口响应与 YAML 在线视图保持脱敏，并在开启局域网监听时校验密钥长度至少为 8 位。
  - 在「概览」页端口卡片、安全徽章及运行时监听列表中动态展示当前管理 API 绑定状态（`127.0.0.1` 或 `0.0.0.0:<端口>`）以及 Neko Master 接入 Host / Port 提示。

可在管理台「更新」页面选择「Beta 测试版」检查更新。
