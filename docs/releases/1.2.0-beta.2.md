# GateHome 1.2.0-beta.2

- 代理分流（Mihomo）默认 `DNS 增强模式` 改为「沿用订阅原配置 (`keep`)」：完整无损保留机场自带的 `use-hosts`、`fake-ip-range`、`default-nameserver`、`nameserver` 与专线 `nameserver-policy`，且不注入 `proxy-server-nameserver` 以保障专线入口调度生效；无订阅冷启动仍提供可用 `fake-ip` 基线。
- 新增「专线 DNS 策略 (`nameserver-policy`)」管理：支持展开查看当前订阅已继承的专线 DNS 条目，并支持增量添加、启用/停用与删除自定义域名 → DNS 映射而不覆盖机场条目。
- 新增可选自定义「DNS 监听端口 (`dns.listen`)」：填 `0` 停用，非零时按 `allow-lan` 绑定监听端口并同步校验与 TCP/UDP 转发冲突，运行态状态条提供地址一键复制且纳入「运行状态」监听清单。

可在管理台「更新」页面选择「Beta 测试版」检查更新。
