# GateHome v1.0.0-beta.9 测试版

本次修复迁移复核确认的普通 HTTP 兼容、路由配置差异和命令面板交互问题，保留 Go 业务模型、数据库、管理员账号及既有配置。

- 普通局域网 HTTP 下恢复新增反代组/路由、端口转发、IP 规则订阅、DDNS、证书、防火墙和发现服务导入。ID 使用安全随机数生成，不依赖仅在安全上下文可用的 `crypto.randomUUID()`。
- 域名输入明确区分“子域名前缀”和“完整域名”，支持 `app.home` 等多级前缀；编辑已有外部完整域名时保留原值。新路由与发现服务根据所属组默认选择 HTTPS，切换组时匹配可用协议。
- 发现服务支持批量选择防火墙、编辑名称、选择是否导入图片，恢复对不受信任 HTTPS 上游的导入限制。
- 补回关闭独立访问验证后显式清除密码、反代卡片查看对应流量入口。冻结时长缺省展示与旧版统一为 60 分钟，已保存的明确时长继续保留。
- 命令面板在搜索时复位选中项、键盘移动时滚动可见；使用原生模态弹窗约束背景焦点，并在 Escape 关闭后恢复焦点。补充键盘焦点样式与侧栏关闭按钮名称。
- 新增浏览器回归并接入控制台/发布 CI，在真实非安全 HTTP 源下操作表单、保存配置、验证冲突和发现服务导入，不只检查页面加载。

## 安装与更新

本版标记为 GitHub **Pre-release**。较早版本在“更新”选择“Beta 测试版”后检查安装；也可上传 `gatehouse-1.0.0-beta.9-update.zip`。检查结果可能缓存 5 分钟。已运行 `1.0.0` 的实例版本排序更高，更新器不会将其降级为 Beta。

附件提供 Linux amd64、arm64 完整安装包、双架构更新 ZIP 和 `gatehome-SHA256SUMS`。正式版 Latest 不变。更新 ZIP 只替换业务程序；Docker 启动器更新应使用本标签源码重建镜像。

升级前停服保存 `config`、`log`、`data`、`sunpanel` 四个目录，包含 `data/route-traffic`。网页备份 ZIP 和历史更新快照不含历史流量；已有数据升级不要执行 `init`。恢复历史版本会回到备份时的程序、配置和账户。

## 验证

前端 31 项自动测试、生产构建、真实浏览器普通 HTTP 回归、Go 全量测试及 `go vet`、原版 12 组专项检查通过。浏览器验证了全部七类新增弹窗、实际路由保存和密码清除、协议/域名前缀、流量跳转、真实发现服务扫描与策略保存、并发冲突草稿，以及命令面板筛选、Tab/Escape 和手机布局。所有测试使用临时模拟数据，不分发测试账号、凭据或数据库。
