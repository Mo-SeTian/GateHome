# GateHomePage 彩霞主题与地址选择

默认主题改为已确认的彩霞方案：暖黄、珊瑚粉、紫色和蓝色背景，半透明浅色卡片与紫色操作按钮。时钟默认黑色，0.0.36 起可在“编辑桌面 → 桌面设置”中选择时钟文字颜色或输入 HEX 色值；每个用户独立保存，备份恢复包含此设置。日期和搜索框在页面顶部居中；GateHomePage 品牌位于底部中央。原有默认主题配置会自动呈现新版，用户上传的背景和自定义 CSS 保留，自定义 CSS 仍可覆盖默认布局。

右下角浮动按钮展开“编辑桌面”和“我的账号”；进入编辑后，同一菜单入口变为带勾选图标的“完成编辑”，点击后退出编辑并收起菜单。菜单支持再次点击、点击外部和 Esc 收起；键盘操作保持焦点可见。登录后“我的账号”显示当前用户名，可切换账号或退出。账号和密码继续在 GateHome 管理；首页不增加另一套账号管理。编辑模式下显示原有分组、页面、应用、组件、桌面设置与反代导入工具，完成后恢复访问卡片。

手机端使用横向图标卡片。每页行数、桌面列数和手机最多列数继续由页面设置决定；窄屏自动降低列数并增加圆点续页，应用不会丢失。圆点、键盘、鼠标滚轮、鼠标拖动及触摸滑动翻页保留。菜单和按钮兼顾手机安全区域，减少动态效果偏好仍生效。

## 自动选择服务地址

不再显示内网/外网手动切换。应用有两种地址时，初始链接为外网；访问者浏览器探测到内网可达后使用内网地址。打开应用时再次使用该探测结果，失败或超时则打开外网。只填写一种地址时直接使用该地址。普通点击和快捷键打开均保留新标签页访问。

浏览器仅对配置的内网地址所属源的 `/` 发起 HEAD 请求，不携带 Cookie、请求体、自定义请求头或 Referer，也不发送配置链接的路径和查询参数。跨域响应使用 no-cors，不读取服务内容；根据浏览器规范允许跟随重定向，但仍保持 HEAD、无凭据和无来源信息。返回 HTTP 错误或登录页也表示服务有网络响应，不代表应用自身健康或已经登录。

同时探测最多 4 个可见应用，相同源合并请求，结果缓存 30 秒，单次最长 1.2 秒。切换用户或退出登录会清空缓存。探测由访客浏览器进行，服务器不会替访客访问内网，也不会进行端口扫描。

浏览器可能因本地网络权限、混合内容、证书错误或服务策略阻止探测，这时安全地回退外网，不绕过浏览器保护。Chrome 支持在安全上下文申请本地网络权限；其他浏览器的支持程度不同。HTTPS 页面上的普通内网域名可使用本地地址提示；IP 和 `.local` 由浏览器判断，避免将回环地址误标为其他网络范围。参见 [Chrome 本地网络访问说明](https://developer.chrome.com/blog/local-network-access)、[MDN targetAddressSpace](https://developer.mozilla.org/en-US/docs/Web/API/Request/targetAddressSpace) 和 [Fetch 标准](https://fetch.spec.whatwg.org/#main-fetch)。

Page 文档的连接策略允许 HTTP/HTTPS 探测，脚本仍仅同源、图片仍仅同源或 data，禁止嵌入和外部表单提交。GateHome 管理页面的连接策略不变，Page 账号权限、私有桌面隔离和备份目录结构保持原有行为。
