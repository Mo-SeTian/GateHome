# 管理员账户

从 0.0.25 起，管理登录须同时填写账号与管理密码。已有安装和旧备份迁移为默认账号 `admin`，原管理密码保持有效；首次安装也可在交互 `init` 中指定账号。账号区分大小写，支持 1–64 字节，不含控制字符或首尾空格。管理密码保持 12–72 字节。

点击右上角账户按钮打开“管理员账户”。填写管理员账号和当前管理密码；需要改密码时填写并确认新管理密码，留空时只修改账号。保存成功后全部管理员会话失效，包括当前页面；使用新账号和管理密码重新登录。不需要重启业务服务。

管理账户保存在私有状态中的 `admin_username` 与 bcrypt `password_hash`，账户读取 API 只返回已登录用户的账号，不回显密码或哈希。写入 API 验证登录、同源请求、当前密码和输入格式，并受验证限流保护；写入失败保留原账户和会话。登录与账户修改同步，防止修改后并发登录再创建旧凭据会话。

配置更新不会修改管理账户；管理账户更新也不会修改反代独立访问账号、密码哈希及服务会话。管理密码、反代访问密码和出站代理密码是三种独立凭据。管理员账号与哈希纳入加密备份和恢复；登录会话不备份。

`gatehouse init` 用原配置目录设置或重置管理员账户，账号留空保留现有账号，密码输入不回显；如果服务仍在运行，完成后重启服务。旧安装的启动器需通过安装脚本更新，才能使用新版交互账号设置；网页更新只更新业务程序。

验证包括：旧文件迁移及密码保留、备份恢复、账号密码组合、只修改账号、当前密码校验、全部管理员会话撤销、配置和服务账号不变、未登录及跨站拒绝、写盘失败保留原状态，前端确认与字节长度校验、密码字段清理和重新登录提示。命令：

```sh
go test -race ./...
go vet ./...
node scripts/account_checks.mjs
```
