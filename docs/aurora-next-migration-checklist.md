# GateHome Aurora Next 迁移验收清单

`develop` 从 `0.9.0` 开始迁移。以原版管理端为功能基线，保留两组 17 项菜单。每批通过本机验收后提交至 `develop`。17 页、旧数据升级和 Go 单二进制全部通过后，将 `VERSION` 升至 `1.0.0`。

## 基线验证

- 在 `frontend/` 运行 `npm ci`、`npm run build`，然后按前端 README 设置 Go 管理端地址并预览生产构建。
- 用现有 Dockerfile 构建镜像，沿用 `compose.bridge.yaml` 的四个目录挂载。将 `GATEHOME_RUNTIME_DIR` 指向独立测试目录，测试管理端口绑定本机回环地址。
- 验证原版管理端的健康检查、登录、退出和版本。新实例用 `init` 初始化一次，旧数据演练使用已有账户和完整数据目录副本。

## 公共功能

- [x] 登录、退出、会话恢复和过期回跳使用 Go 管理端会话。错误提示、密码重置说明、账户保存后的会话失效与原版一致。
- [ ] 侧栏菜单、顶栏和命令面板可导航到所有页面。测试桌面和移动端、双主题、加载、空数据和失败反馈。
- [ ] 配置页提交完整配置和编辑时取得的 `revision`，仅修改当前表单管理的字段。校验并发冲突、秘密字段的保留或清空语义，以及重启提示。

## 工作空间

| 页面 | 验收功能 |
| --- | --- |
| [ ] 概览 `#/overview` | 已验证网关状态、系统遥测、流量与访问趋势、地区分布及服务健康。待迁移原版组件显示与顺序配置。 |
| [ ] 反向代理 `#/routes` | 反代组和路由的创建、编辑、启停与删除，搜索筛选、上游发现及健康检查、服务图片、前置鉴权、防火墙关联。用实际 HTTP/HTTPS 请求确认代理生效。 |
| [ ] 端口转发 `#/forwards` | TCP/UDP 规则的创建、编辑、启停与删除，监听地址和目标校验，待重启与生效状态。用实际连接验证转发。 |
| [ ] 浏览器首页 `#/sunpanel` | 首页服务启停、端口和访问地址，打开 SunPanel、导入已启用反代并读取既有首页数据。 |
| [ ] 动态域名 `#/ddns` | 账户组及记录配置、IPv4/IPv6 地址检测、解析状态、网络设置、手动同步与任务结果。 |
| [ ] SSL 证书 `#/certificates` | ACME 配置、证书任务的新增与编辑、申请、续期和状态，验证测试证书加载。 |
| [ ] 订阅管理 `#/subscriptions` | IP/CIDR 规则源的新增、编辑、启停、删除和手动刷新，显示抓取与解析结果，并验证订阅更新后关联 IP 组生效。 |
| [ ] 防火墙管理 `#/access` | 防火墙和 IP 组管理、包含和排除、默认动作、WAF 模式与例外、自定义规则和限速。验证关联反代的实际放行、审计和拦截。 |
