# GateHome 1.0.1-beta.13

- 新增统一全局搜索与命令面板（`⌘K` / `Ctrl+K`）：支持按名称、域名、上游地址、端口、CIDR 或关键字跨模块搜索全部页面、反向代理服务与反代组、TCP/UDP 端口转发规则、DDNS、SSL 证书、防火墙策略、订阅源与通知记录，并支持分类筛选、移动端顶栏一键唤出与跳转自动定位过滤；端口转发页同步新增本地搜索框。
- 安全性全面加固：
  - 管理台入口接入 `TrustedProxies` 真实客户端 IP 解析，防止反代暴露场景下登录限流误锁合法管理员并修正审计日志来源 IP；封堵未开启反代访问时通过普通 HTTP 反代转发头绕过 `AdminAccess` 来源校验的风险。
  - 图标库本地上传、GitHub 导入与备份恢复统一接入 SVG 安全校验，修复 `imageasset` 多值 `url(...)` 与 CSS 转义绕过。
  - 统一出站请求 SSRF 拦截（含 AWS IPv6 元数据地址 `fd00:ec2::254`、云元数据 IP 及出站代理地址校验），并修复外链路由图标导入未走已配置出站代理的问题。
  - 优化 WAF 请求体内存信号量预留策略（防止高 `BodyLimit` 策略下单个小请求占满全局配额）与 `detect` 模式异常容错；为端口转发增加 TCP 半关闭截止时间与被拦截 UDP 会话即时退出。
- 功能与可靠性修复：
  - 兼容上游可信 TLS 卸载代理后方的反代独立密码认证（`/.gatehouse-auth`）与 `Secure` Cookie 下发。
  - 修复重复导入 GitHub 图标包时 `icons.json` 与已有图标文件未覆盖更新的问题。
  - 修复更新启动失败自动回滚后残留无效 `update-backups` 快照挤占历史回滚点的问题，以及 Beta 更新检查出错时降级检测更高正式稳定版、空渠道下载默认识别。
  - 修复 WebSocket（HTTP 101 升级）流量未计入持久化历史统计、IP 解封规范化及共享健康探测被首个请求断连误取消等问题。

本版本为预发行版。当前运行 Beta 版本时，可在管理台「更新」页面默认检查 Beta 测试版更新，并在存在更高正式稳定版时自动切换至稳定版渠道。
