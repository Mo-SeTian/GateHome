# 记录查询与 IP 归属地

0.0.17 新增独立的 **防火墙拦截记录** 页面，统计中的防火墙明细移至此处，统计汇总指标继续保留。

## 查看与筛选

- **防火墙拦截记录**：IP 规则、Coraza / OWASP CRS、HTTP 规则、访问限速、系统保护和冻结 IP 的实际拦截，以及仅记录命中。
- **统计 → 最近安全事件**：上述事件及独立服务账号验证失败、验证请求拒绝和验证速率限制。此列表的筛选独立于上方图表的统计时间与反代规则。
- **日志 → 反代日志**：所有 HTTP 代理请求，来源 IP 单独列出；IP 下方标注归属地，规则命中显示在详细说明中。

防火墙记录和最近安全事件均支持反代服务、防火墙、检测类型、处理结果、精确 IPv4 / IPv6、检测规则编号、开始 / 结束时间和关键词组合筛选。检测类型与规则编号必须匹配同一个命中；例如选择 CRS 后填写 HTTP 自定义规则编号不会返回记录。来源 IP 采用规范化精确比较，接受等价 IPv6 写法及 IPv4 映射地址。点击 **筛选** 应用条件，**重置** 清空条件。

每页可选择 20 / 50 / 100 / 200 条，并用页码或上一页 / 下一页翻页。翻页沿用第一次查询的最高日志编号和已应用筛选条件，新请求不会插入当前分页快照。刷新或重新筛选从第一页读取最新记录。失败保留上次成功结果并展示原因；旧请求不会覆盖新的结果。记录仍受现有轮转和最多 5000 条保留限制，快照不能恢复已轮转删除的数据。

仅记录命中保存当时的防火墙标识与名称，改名后历史记录保留原名。旧版没有保存的防火墙详情不补造。普通后端 401 / 403 不算作 Gatehouse 账号失败或防火墙拦截；有检测命中的后端 403 仍归类为仅记录，因为 Gatehouse 已转发请求。

## 离线归属地

使用 [ip2region 官方项目](https://github.com/lionsoul2014/ip2region)的 IPv4 / IPv6 XDB 数据库，固定来源提交 `02f04aa559acd954d94f77086e8ebe32483b365b`。来源、哈希、大小及原始许可证保存在 `internal/gateway/geodb/SOURCE.json` 和 `LICENSE.md` 中。数据覆盖可用的国家、省 / 州、城市及网络运营商；缺失字段自动省略，保留数据库中的地区名称。

数据库以 gzip 内嵌，运行不需要 API key 或外部查询。查询只在经过管理员认证的日志响应中进行，不写回原日志，也不参与代理转发。IPv4 / IPv6 数据分别按首次使用加载，解压后合计约 46 MiB，各查询使用独立搜索器共享只读数据库。没有持续增长的 IP 查询缓存。

内网、回环、链路本地及保留地址直接标注对应类型；查不到时显示 **归属地未知**。来源 IP 为实际连接地址，转发请求头不会替代它。归属地是地址段估算，不能代表用户的精确位置；代理、VPN、CDN 和任播服务可能显示其出口或登记地区。数据库随后续程序版本更新，当前版本不自动下载更新。
