# GateHome 1.0.1-beta.12

- 更新渠道智能识别：当当前运行为 Beta 测试版时，更新检测默认选择「Beta 测试版」渠道；若检测到高于当前版本与最新测试版的正式稳定版，将自动切换至「正式稳定版」渠道并提示升级。
- 恢复顶栏右上角快速通知中心：点击铃铛图标可展开轻量下拉通知列表，支持快速已读、全部已读、删除、跳转对应页面及进入完整「通知中心」页面。
- 优化通知中心消息分层（含原 1.0.1-beta.11 改动）：常规配置保存、链接复制与一般成功提示仅展示页面浮动 Toast，不再写入通知中心历史或增加未读角标。
- 优化 UDP 端口转发 socket 缓冲区配置，修复 Linux `-race` 环境下大报文并发 UDP 转发测试偶发超时的问题。

本版本为预发行版。当前运行 Beta 版本时，可在管理台「更新」页面默认检查 Beta 测试版更新，并在存在更高正式稳定版时自动切换至稳定版渠道。
