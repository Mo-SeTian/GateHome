# GateHome 1.0.0-beta.16

- 工作空间新增图标库，支持中英文和拼音检索、来源与形态筛选、批量上传和本地图标预览。
- 支持异步导入 HD-Icons 等采用 `border-radius/`、`circle/`、`svg/` 目录的公开 GitHub 仓库。可选择 GitHub 直连或 GH-Proxy。自行部署镜像时，在服务环境中设置 `GATEHOME_ICON_IMPORT_MIRROR` 为 HTTPS 镜像前缀。
- 反代编辑器支持从图标库选择图标，可用方向键和回车操作。移动端使用底部抽屉，已有反代图片引用继续可用。
- 图标文件和索引写入 GateHome 数据目录的 `icons/`。Docker 对应 `/data/icons`。备份收录已用于反代路由的图标。整库迁移时请一并保留此目录。

使用 systemd 安装版时，请通过完整安装包升级启动器。旧版启动器无法处理使用了图标库路径的配置快照。Docker 用户通过更新镜像同步升级启动器。
