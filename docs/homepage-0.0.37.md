# GateHomePage 0.0.37

电脑端和手机端采用紧凑图标桌面，应用名称显示在图标下方。原有应用描述继续保存，可在编辑应用中修改；首页不再显示宽卡片描述。默认背景为内置海岸图片，已有自定义背景继续生效。

## 操作入口

- 右上角菜单：编辑桌面、桌面设置、账号切换和退出登录。完成编辑仍在同一菜单中。
- 桌面加号：登录后添加应用；没有分组时先添加分组。
- 设置列表：布局与页面、背景图片、时钟颜色、搜索引擎、桌面显示、自定义 CSS、从 GateHome 导入。手机端全屏打开，电脑端居中弹窗。
- 编辑模式：点击应用编辑，删除按钮带确认；删除后可从编辑菜单撤销。

## 布局与兼容性

新增页面默认 3 行、桌面 6 列、手机端最多 4 列。手机端可设置 1–5 列，实际列数按可用宽度缩减，避免窄屏溢出；已有页面不会自动覆盖行列配置。分组内圆点、鼠标滚轮、拖动和触摸翻页继续保留。

时钟颜色、自定义搜索、背景上传或 URL 导入、自定义 CSS、多用户独立桌面和内外网自动选择继续使用原有配置与接口。设置项分别保存，不覆盖其他设置。账号密码仍由 GateHome 管理，数据仍保存在 data/page，备份恢复结构未变。旧自定义 CSS 如依赖宽卡片布局，可能需要调整以适应图标布局。
