# GateHome 1.0.0-beta.7

GateHome 1.0.0-beta.7 重点优化了反向代理路由创建/编辑弹窗中的「服务图片与自定义图标」选择器组件在移动端和桌面端的布局表现与交互体验。

## 🌟 核心改进与修复说明

### 1. 彻底修复「选择本地图片」按钮纵向堆叠变形问题
- **清除样式污染**：在全局表单规范 `form-tokens.css` 的 `dialog label` 排除选择器中补充 `:not(.custom-file-btn)`，杜绝弹窗内的自定义上传按钮被误套用纵向列排布规则。
- **强制单行居中排布**：在 `RouteImagePicker.vue` 中明确为 `.custom-file-btn` 声明单行水平对齐（`display: inline-flex !important; flex-direction: row !important; align-items: center !important; gap: 6px !important;`），图标与文字保持严格的水平工整居中，彻底消除变成“大方块”的视觉缺陷。

### 2. 重构服务图片选择器移动端布局结构
- **上下两段式清晰分区**：
  - **上半行**：左侧为 `44×44px` 圆角预览槽，右侧紧跟【选择本地图片】按钮（配置图片时附带【恢复默认】清除按钮）及浅灰色格式说明文字，比例协调。
  - **下半行**：整行铺开在线图片输入框与【导入】按钮，高度统一为 `32px`，自适应伸缩填充。
- **杜绝移动端横向溢出屏幕**：
  - 修复标题和副标题单行强行撑破卡片的问题，允许说明文字在窄屏下自然换行。
  - 为在线地址输入框增加 `min-width: 0` 和 `box-sizing: border-box`，确保在 360px ~ 390px 紧凑手机视口下右侧【导入】按钮严格对齐容器边缘，绝不横向突起或截断。
