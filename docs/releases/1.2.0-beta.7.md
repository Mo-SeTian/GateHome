# GateHome 1.2.0-beta.7

- **右上角通知中心优化**：将消息列表顶部的「故障推送」快捷入口替换为「一键清除」按钮，支持一键清空所有已读与未读通知并持久化。
- **自定义策略组/规则 YAML 编辑器交互与示例完善**：「策略组与节点」「自定义分流」下的「YAML 编辑」面板修复顶部操作按钮错位问题，恢复右侧对齐布局；同时在 YAML 头部注释中内置 `select` / `url-test` / `fallback` 与常用分流规则示例，方便参考改写。
- **配置文件与日志图形字符适配**：扩展 `--mono` 与 `--sans` 的 Emoji 彩色字体及中文字体回退链，并为配置文件查看器、YAML 编辑器与运行日志启用 `font-variant-emoji: emoji`，修复配置中 `⚓`、`🚀` 等图形字符显示异常或重叠问题。

可在管理台「更新」页面选择「Beta 测试版」检查更新。
