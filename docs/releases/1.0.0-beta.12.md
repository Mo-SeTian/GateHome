# GateHome 1.0.0-beta.12

修复 beta.11 第二轮审查确认的六项问题，重点补齐 MCP 授权持久化与响应权限边界。本次预发行同时包含 beta.10–11 的界面和安全改进。

## 主要修复

- 全局 Token 仅授予首页修改后，可以正常重启、继续保存配置和检查备份；仍拒绝启用无有效权限的授权。
- 无查询权限的 MCP 配置写入只返回成功状态与 revision，避免返回其他配置分区；读写客户端保留原响应。
- 管理员账户改用原生模态弹窗，约束键盘焦点、阻止背景操作并恢复触发按钮焦点，保留账户修改后的退出重登。
- 手机 MCP 权限卡片实际高度修正为 44px，IP 来源字段统一布局，证书错误与界面说明采用真实退避策略。

## 同时包含的改进

- MCP 首页修改与网关配置分别授权，安全策略修改单独控制；新增显式可信前置代理设置，默认仍使用实际连接 IP。
- 补齐日志敏感信息脱敏、满载计数器过期回收及 WAF 超大请求体前缀检测，保留完整正文回源和检查范围提示。
- DDNS 有界并发及重复触发合并、证书失败退避、会话按最早到期淘汰、备份期间快速重试反馈。
- 消除 MCP 双复选框，统一表单布局，改进 Toast 安全区、图片格式提示、表格滚动及后台轮询。

## 升级与下载

附件包含 Linux amd64 / arm64 安装包、双架构更新 ZIP 和 SHA-256 校验文件。已有控制台可在更新页面选择 Beta 渠道，或上传本版更新 ZIP 预检后应用。

沿用现有配置、SQLite、账户与凭据；升级前建议停服备份 `config`、`log`、`data`、`sunpanel` 四个目录。管理入口继续使用独立主机名和 HTTPS。新增权限限制由新版执行，手动降级到旧程序前应停用受限 Token；内置历史回退会同时恢复当时的配置和授权。

前端 33 项单测、Go 全量 race、真实浏览器重启、账户保存与多宽度检查通过。本机主实例已运行 beta.12 并验证原数据保留。详见 [本版修复记录](https://github.com/Mo-SeTian/GateHome/blob/v1.0.0-beta.12/docs/audit-remediation-1.0.0-beta.12.md) 和 [前一轮修复记录](https://github.com/Mo-SeTian/GateHome/blob/v1.0.0-beta.12/docs/audit-remediation-2026-11-10.md)。
