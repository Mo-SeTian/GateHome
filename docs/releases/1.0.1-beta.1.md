# GateHome 1.0.1-beta.1

- 图标库新增「通过链接导入」，输入 HTTP / HTTPS 图片链接后可先预览，再确认导入；支持 PNG、JPG、GIF、WebP、ICO 和 SVG。
- 预览通过服务器下载和校验，取消预览不会保存图标。确认导入保存预览中的同一份图片，修改链接后须重新预览。
- 反代图片的 URL 导入支持 SVG，包括带查询参数和内部样式的图片；保存为本地矢量图片，按原比例显示。
- SVG 反代图片可随路由导入 SunPanel，并进入备份与恢复流程。SVG 图片沿用反代图片的 128 KiB 存储上限，图标库单张图片上限为 5 MiB。

本版本为预发行版，管理台「更新」中可选择「Beta 测试版」渠道检查更新。
