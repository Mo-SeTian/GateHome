# GateHome 1.0.0-beta.22

- 反代卡片显示并复制完整访问 URL，包含协议、域名和所属组的监听端口。HTTPS、HTTP 分别使用对应端口，80 和 443 也明确保留；未配置对应监听时禁用复制。
- 反代服务按组独立展示，每组提供服务数量、监听状态和编辑、启停、删除操作，支持独立折叠、键盘操作和记住折叠状态。
- 搜索或切换筛选时展开匹配组，保留空组管理；保存组端口后同步更新卡片访问地址，监听变更仍需按原流程重启生效。
- 适配手机、横屏及浅色、深色主题，完整地址可换行显示，手机端分组控制与地址复制热区至少 44px。
- 增加 URL 协议与端口单元测试，以及真实剪贴板、分组折叠、状态保持、筛选、端口编辑和业务流程的浏览器回归检查。

Linux 安装版若仍使用早于 beta.16 的启动器，请通过完整安装包同步升级启动器和业务程序，以支持图标库引用的备份与后续在线更新。重新安装保留配置、日志、数据和 Sun-Panel 目录。
