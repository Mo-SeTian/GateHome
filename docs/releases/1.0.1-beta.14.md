# GateHome 1.0.1-beta.14

- 日志页面一键「封禁 / 解封 / 加白 IP」闭环：
  - 访问日志（`/logs`）与防火墙拦截记录（`/firewall-logs`）表格行内实时标注 `已封禁` / `已加白` 状态，并直接提供 `封禁` / `解封` 快捷入口。
  - 日志详情弹窗新增来源 IP 快速处置面板，支持一键按该 IP 筛选、快捷封禁时长预设（15 分钟 / 1 小时 / 24 小时 / 7 天）、一键解除封禁，以及一键加入绑定防火墙的最高优先级「日志快速加白」白名单并同步放行。
- 运行状态（`/runtime`）趋势迷你图（Sparkline）：
  - CPU 与内存监控卡片保留当前会话最近 30 次采样轨迹并绘制轻量 SVG 折线图与渐变填充区域，支持动态刻度、深浅双主题与告警色标，同时展示采样次数、峰值与均值。
- 修复日志页面点击「更多筛选」展开高级筛选抽屉时，因继承 `.report-form` 对齐样式导致抽屉塌缩至最右侧纵向错位的问题。

本版本为预发行版。当前运行 Beta 版本时，可在管理台「更新」页面默认检查 Beta 测试版更新，并在存在更高正式稳定版时自动切换至稳定版渠道。
