# GateHome 1.0.0-beta.27

- 修复 SunPanel 自动内网检测误判：调整跨域探测请求，普通 HTTP、登录响应及正常的 307 跳转可正确选择内网地址。
- 浏览器探测前由服务器核验完整跳转链，保留 HTTPS 证书检查、请求超时与失败回退；网络详情明确服务器检查对应“实际打开地址”。
- 支持将在线 SVG 图片保存为本地矢量图标，兼容带查询参数的链接及常见内部样式；图片和在线图标两种入口均按原比例完整显示。
- SVG 导入沿用图片归属、文件管理和整站备份，保留脚本、事件与外部资源校验；保存后不再依赖远程图片来源。
- 增加真实跨域内网探测、307 跳转、SVG 预览与本地保存、来源停用后刷新及手机显示回归。
