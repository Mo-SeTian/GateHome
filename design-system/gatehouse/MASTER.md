# Gatehouse 0.0.15 界面与交互规范

设计沿用用户选定的第二版配色与全局导航，内容区按后续要求改为可折叠分组。使用 ui-ux-pro-max 的组件、间距与可访问性规则，以及 spt-interaction-motion 的可中断转场。技术栈保持 Go embed + 原生 HTML/CSS/JS，不增加外部字体或动画框架。

## 页面结构

各个管理页面各自保留路由与职责。首页为概览；设计展示板中的反代、手机编辑和统计示例属于不同页面。

反代页保留 184px 全局导航；每个组占内容区一行，统一面板框住组内规则，独立收起 / 展开。取消组侧栏和右侧编辑区，所有宽度均使用原生模态窗口，680px 以下全屏编辑。编辑器开闭不修改配置，保存成功才提交结果。请求进行中暂停开启其他编辑项，防止删除后旧列表索引指向其他服务。

所有宽度均在页头显示“添加反代组”，每组标题保留“添加代理服务”。手机操作至少 44px 高。DDNS 组、防火墙策略和证书任务共用独立分组折叠；收起后保留摘要、状态与编辑入口。折叠状态在页面切换和刷新数据时保留，本次会话结束后重置；保存代理服务后展开所属组。

SSL 页的邮箱、签发环境、自动申请和条款选项集中于“证书配置”弹窗；每个证书任务为一个可折叠面板。全局设置只在配置弹窗编辑，任务详情仅显示其当前环境。

## 视觉与组件

- 主色 `#4256d5`、悬停 `#3447ba`；工作区 `#f6f7fa`；白色表面；正文 `#252c3e`；次要文字 `#667085`；边界 `#e2e6ee`。
- 成功、警告、危险各自保留语义色与文字；正常流量图表使用 `#22825b`，图例与曲线一致。
- 系统中文字体；IP、域名和端口使用等宽字体，读数使用等宽数字。标题 24–28px，面板标题 16px，控件与正文 13px，说明 12px。
- 桌面操作与输入至少 40px，手机至少 44px；状态标签至少 24px，不当作操作按钮。手机输入字号 16px。
- 页面间距 24px，面板内边距 24px，手机外边距 16px；面板圆角 10px，按钮 7px，输入 8px。
- Tabler Icons 3.49.0，24px 网格、2px 线宽，SVG symbol 本地加载。装饰图标隐藏于辅助技术，图标按钮提供名称，许可证随源码保留。
- 分组标题使用 34px 类别图标底块与 16px 折叠图标；展开朝下、收起朝右。编辑、删除、启停、筛选、保存、分页、外链统一为 SVG，按钮保留文字；外链补充新标签页说明。登录与冻结提示使用相同图标形态，禁止把 Unicode 字符当作操作图标。
- 标题与状态同组，操作区单独对齐。反代协议、防火墙、访问账号和运行状态各占一列。所有破坏性操作使用危险语义。
- 桌面表格统一表头、行间距和操作对齐；手机变为保留字段名的列表，IPv6、长规则名和日志路径换行展示。统计图表适配容器，不扩大页面宽度。
- 编辑表单共用固定标题、可滚动内容和固定底部按钮。所属组、子域名 / 访问域名和完整域名预览置于表单前部，始终展开；保存或离开空域名字段时显示字段旁的提示并关联辅助技术，填写后清除；独立服务账号明确与管理员登录分开，密码不回显。

## 动效与输入

| 状态 | 交互和提交 | 完成与中断 |
| --- | --- | --- |
| 页面切换 | 路由立即更新，透明度和 Y 8px 入场 | 240ms；新导航取消旧动画；后台刷新不重复入场 |
| 编辑打开 | 所有宽度原生模态并约束焦点 | 240ms；从当前状态接管，不丢失正在编辑的字段 |
| 编辑关闭 | 取消 / Esc 不保存；成功提交后关闭 | 140ms；旧退出不能关闭重开的编辑器；恢复触发按钮焦点 |
| 按压反馈 | Y 1px，保留按钮布局尺寸 | 100ms；释放恢复 |
| 数值更新 | 实际值立即显示，局部透明度反馈 | 160ms；仅变化的读数动画 |
| 请求进行中 | 禁用重复提交、aria-busy；失败保留表单 | 完成恢复操作；统计保留有效结果，新请求优先 |
| 手机导航 | 抽屉打开使主区 inert，Tab 循环；选择目标后切页 | 240ms；Esc 与遮罩取消并恢复焦点 |
| 分组折叠 | hidden 与 aria-expanded 立即同步；折叠图标旋转，展开内容淡入 | 160ms；反向操作取消旧动画，键盘 Enter / Space 与指针一致 |

减少动态效果时跳过位移与缩放，保留加载和结果语义。菜单支持键盘打开和 Esc 关闭。长弹窗内滚动不影响标题与按钮；保存不会回显或覆盖留空的已存密码。

## 2026-11-07 全局界面重构 · 选定第一版

第一版紧凑分组工作台作为 GateHome 全部管理界面的共同基准，新增 `internal/gateway/web/ui.css` 在原有样式后加载。覆盖 14 个管理页面、登录、账户、编辑弹窗、操作菜单、帮助、等待与错误状态；Sun-Panel 的桌面、设置、弹窗、尺寸与网格保持现状，不向 iframe 注入样式。

- 保留 184px 导航、系统中文字体、Tabler 图标和 `#4256d5` 主色；顶栏 56px，桌面内容外边距 24px，面板间距 20px，圆角 8px。手机面板间距 12px，输入字号 16px，触屏操作至少 44px。
- 代理列表仍按独立可折叠组展示，编辑始终使用模态框。桌面服务行约 59px，保留内网地址在上、外网入口在下的现有语义，组内服务发现移入操作菜单。运行状态、端口、保护策略、独立账号与故障诊断直接展示。
- 健康工具栏区分真实正常、异常、等待检测和暂停；不把未采样的数据当作故障。设置在独立弹窗修改，保存成功才关闭，取消不修改配置。最近事件在重新渲染与刷新之间保留。
- 所有编辑弹窗只有一个滚动正文和固定操作区；Tab / Shift+Tab 在首尾循环，关闭后恢复触发位置。普通提交按钮不进入操作命令分支。操作菜单按剩余空间左右对齐及向上展开，缩放时重新定位。
- 页面与导航入场 240ms，退出 140ms，菜单、帮助、折叠与局部数值反馈 160ms，按压 100ms。快速切换沿用可中断原生动画；减少动态效果时保留状态、跳过位移。
- LeiBox 仅接入实际适配的无依赖点阵组件：`internal/gateway/ui/leibox/ai-generating/` 保留完整下载源码。等待状态由原有请求决定，不模拟百分比；连接、离开视口、减少动态效果与移除均有对应清理。
- `node scripts/build_leibox.mjs` 生成脚本和外部样式，不增加动画框架，不放宽 `script-src 'self'` / `style-src 'self'`。来源与适配见该组件目录的 README。

验证：`node scripts/ui_checks.mjs`、现有 10 组前端回归检查、`CGO_ENABLED=0 go test ./...`、`CGO_ENABLED=0 go vet ./...`；浏览器验收的页面、弹窗、尺寸与已知边界记录在根目录 `design-qa.md`。

## 2026-11-07 手机端第二轮 · 未发布预览

针对 v0.0.61 手机端仍然沿用桌面字段逐行堆叠的问题，按手机上的查看、切页和编辑流程重新组织界面。方向采用 Framed sheet：桌面为浅色外框与白色内容区，手机使用浅灰工作区、白色服务条目和固定底部导航。保留系统中文字体、品牌标志与既有配色；产品特征是同一服务的内网地址、访问域名和健康状态。

- 680px 以下显示概览、服务、首页、日志与更多五个入口；更多面板承载全部 14 个页面，支持 Esc、焦点循环和关闭后的焦点恢复。底部预留安全区，浮动菜单向上避开导航。
- 反代条目以服务名称与健康状态开头，内网地址和访问域名并列，保护配置与操作在底部；桌面继续使用表格。分组操作、健康检查和页头工具收紧，减少列表前的堆叠。
- 日志与安全记录的筛选默认收起，展开后编辑和应用；大屏恢复展开。多项页头次要操作在手机上合并到菜单，切换到大屏会恢复原按钮及其顺序。
- 手机概览的同级指标使用双列，宽组件独占一行；奇数个统计项的末项占满整行。DDNS 的 IPv4 / IPv6 并列；设置使用单列分区。
- 编辑使用全屏表单，标题与操作区固定，中间内容独立滚动；输入至少 48px，底部适配安全区。缩小可见高度后保存操作仍然可见，取消后恢复编辑按钮焦点。
- 修复更新后仍保留旧页面资源的问题：状态请求发现服务端版本变化时重新载入页面；首次加载和相同版本不重复刷新。更新前已经打开的旧版客户端仍需完整刷新一次。
- 保留已接入的 LeiBox 点阵等待。实时检索的 Glass Tab Menu 固定为四页和六个演示动作，不适合完整管理导航，本轮导航使用现有原生 DOM 与可中断转场，不接入该演示包。
- Sun-Panel 自身源码与 iframe 内部样式保持不变。本轮仅改 GateHome，不触及鉴权、代理转发或服务器配置。

验收：14 页 × 320 / 390 / 768 / 1440 四种宽度无页面横向溢出，手机筛选和大屏展开状态正确；验证登录、日志筛选、次要操作菜单、Esc、焦点恢复及 390×520 可见区域下的表单。12 组前端回归与 Go 测试通过。当前仅为本地可操作预览，尚未发布或更新生产实例。

## 2026-11-07 信号板 · 方案 C 落地

从三个方向中选定“信号板”，并按白哥要求把顶部导航改为侧栏。设计稿与出图留在 `.local/ui-concepts-2026-11-07/`，落地只改 `internal/gateway/web/`，后端零改动。

- 外壳：224px 白色侧栏（品牌 → 工作空间 7 项 → 观察与管理 7 项 → 连接状态与版本 → 账户 → 退出），桌面不再有顶栏，内容区直接是页面标题。≤900px 侧栏转 264px 抽屉，顶部留 54px 细条放菜单与连接状态；断点与既有 `min-width:901px` 规则对齐。
- 反代页：状态带（服务总数 / 正常 / 需要处理 / 监听组 / 最近检查）→ 组筛选胶囊 → 按组的服务卡片网格。卡片三段式：身份（字母块 + 名称 + 域名）→ 内网与域名地址 → 协议/账号/防火墙标签 → 健康页脚。失败服务顶部常驻 3px 红条。
- 组件：`.status-band` `.stat` `.chips` `.chip` `.cards` `.route-card` `.rc-*` 为新增；其余 13 页继续用 `.panel` / `.table-wrap` / `.form-grid`，由 `ui.css` 统一换肤，未改它们的模板结构。
- 动效：卡片入场 320ms、逐张错开 35ms、位移 10px；hover 180ms 上浮 2px；筛选交叉淡入 160ms；折叠与抽屉 240ms；按压 100ms；统一 `cubic-bezier(.2,.7,.3,1)`。检查中卡片顶部 2px 光带 1.15s 循环，只表示正在检查，不表示进度。`prefers-reduced-motion` 下全部归零。
- 断点：≥1401 五格状态带 + 4 列卡片；1201–1500 卡片内距收紧、字号降至 10.5px 以免域名过早省略；901–1200 状态带四格 + 检查卡整行、卡片 2 列；≤900 抽屉 + 2 列；≤680 单列 + 2×2 状态带。

验证：12 组前端回归 + `ui_checks` 新增的卡片/筛选/状态带回归；`CGO_ENABLED=0 go test -race ./...`（115s）与 `go vet` 通过。截图见 `.local/shots/final/`，前后对比 `.local/shots/board-compare.png`。

### 落地后修订（2026-11-07 审查）

- 文字令牌调整为可读优先：`--text #1b2230`、`--muted #55606f`（白底 6.39:1）、`--faint #6b7688`（4.59:1）。重构首版用的 `--faint #98a3b8` 只有 2.54:1，11px 辅助文字不可读。
- 语义色同步加深：成功 `#177049`、危险 `#b93a34`、警告 `#8f5d05`，保证在各自的浅底上仍 ≥4.5:1。
- 手机断点内所有可点元素 ≥44px：导航项、胶囊、重新检查、菜单键、账户与退出；抽屉只让导航区滚动，品牌与账户固定。桌面保持紧凑工具栏（胶囊 30、更多菜单 24），满足 WCAG 2.5.8 的 24px 下限。
- 新增组件样式一律带作用域前缀（`.status-band .stat`），避免与统计页等复用同名类的页面互相污染；这条已在本轮踩过一次。
- 轮询类刷新不得触发入场动画：只有用户主动触发时才播放「正在检查」的扫光。
