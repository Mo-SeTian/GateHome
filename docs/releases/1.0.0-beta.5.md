# GateHome 1.0.0-beta.5

GateHome 1.0.0-beta.5 全面修复并彻底根治了控制台在不同浏览器（WebKit / Chrome / Safari）下的视觉裁切、开关布局畸变、下拉菜单透底及侧栏文本折行等问题。

## 🌟 核心改进与修复说明

### 1. 下拉框与文本输入框文字截断修复
- **精准行高与内边距匹配**：统一将全站 `select`、`.form-select`、`.form-input`、`input[type="text"]`、`input[type="password"]` 的高度设为 `40px`，单行基线 `line-height: 38px`，左右留白 `12px`（下拉箭头处预留 `34px`）。
- **彻底根除文字被横向切掉一半的缺陷**：清理了 `main.css` 中相互冲突的全局覆盖内边距，确保中文字体（苹方 / 微软雅黑）垂直精确居中，文本上下留白均匀、绝不溢出裁切。

### 2. 弹窗与设置页滑动开关布局重构
- **消除“大坨”垂直堆叠方块**：将弹窗（路由编辑、端口转发、健康诊断）中的滑动开关强制约束为 `flex-direction: row` 单行左右两端对齐，高度紧凑控制在 `38px`。
- **引入 `.toggles-group` 容器规范**：反代路由弹窗中的“启用路由”、“使用 HTTPS”、“启用独立账户”采用微毛玻璃分组包裹，左侧标题文字、右侧极光滑动开关，整洁精致。
- **清除局部样式污染**：修复各设置视图 scoped CSS 中裸 `label` 对开关产生的破坏性样式覆盖。

### 3. 右上角用户菜单弹出层防透底
- **提升 TopHeader 页面层级**：将顶部应用栏提升至 `z-index: 100`。
- **100% 实体纯色背景**：浅色模式下为纯白 `#ffffff`，深色模式下为黑曜石 `#0d121e`，配合多重柔和投影，彻底杜绝底层页面右上角“重新读取”按钮穿透 popover 造成的错位重叠现象。

### 4. 侧边栏底部状态栏“退出登录”折行修复
- **防挤压排版**：为 `.login-link-btn` 强制设置 `white-space: nowrap !important;` 与 `word-break: keep-all !important;`。
- **精致微图标**：按钮增加 `<LogOut :size="12" />` 微型退出图标与悬停微光，彻底消除汉字换行为“退出登 / 录”的尴尬排版。

### 5. 报表与统计页面顶部排版与筛选器流式自适应
- **消除单边空白**：优化 `reports.css` 中的 `report-heading` 与 `report-form`，由生硬的固定网格改为自适应流式排布，右侧不再产生大块突兀空白。
- **移动端全宽对称**：报表表单与操作按钮在移动端（≤640px）自适应转为 100% 宽度对称排列。
