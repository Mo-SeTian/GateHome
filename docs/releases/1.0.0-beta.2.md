# GateHome v1.0.0-beta.2 测试版

Aurora Next 控制台界面全面优化版，针对第一版迁移中发现的界面对齐、控件风格一致性、弹窗毛玻璃规范、响应式伸缩等问题完成系统性优化修复。

- **全局表单规范统一**：建立统一的表单控件规范（`form-tokens.css`），将各页面和弹窗中的原生单选/复选框改造为带有滑块光晕动效的 Aurora 极光开关（`.toggle-row` / `.switch`），下拉选择器移除系统原生箭头并嵌入 SVG 双色 Chevron，解决深色模式下展开白闪的问题。
- **高透毛玻璃弹窗（Glass Dialog）**：全系统弹窗统一采用 35px 高透磨砂毛玻璃规范，新增内边缘微光高光与 20px 圆角，规范化顶部标题、内容滚动区与底部操作栏，移除浏览器原生 fieldset 粗糙双线边框与默认关闭按钮样式。
- **栅格对齐与响应式重构**：
  - 概览页 Bento Grid 采用弹性拉伸对齐，彻底消除不等高卡片底部的黑洞空隙；调整平板端断点（<= 1279px 转双列，<= 767px 转单列），解决 1000px~1024px 区间的布局挤压。
  - 反向代理与端口转发卡片网格升级为流式自适应弹性布局，卡片底部操作按钮基线统一对齐，反向代理新增动态业务分类图标着色。
- **诊断与交互细节完善**：上游健康检查弹窗新增规范操作栏，诊断信息结构化呈现为带状态胶囊与延迟指示的可视化卡片；日志详情、手动冻结 IP 弹窗等完成模块化毛玻璃改造。

## 安装与更新

这是 GitHub **Pre-release** 预发行版本，支持在线更新与离线包更新：

1. **在线更新**：在现有 GateHome 控制台进入「更新」页面，更新渠道切换为「Beta 测试版」，点击「检查新版本」，检测到 `v1.0.0-beta.2` 后即可一键执行在线下载、自动备份与重启更新。
2. **离线更新**：在「更新」页面上传 `gatehouse-1.0.0-beta.2-update.zip`，验证 SHA-256 校验和后自动解压并应用。

| 附件 | 用途 |
| --- | --- |
| `gatehome-linux-amd64.tar.gz` | Linux x86_64 完整安装包，包含启动器安装脚本及 systemd 服务 |
| `gatehome-linux-arm64.tar.gz` | Linux ARM64 完整安装包 |
| `gatehouse-1.0.0-beta.2-update.zip` | 网页/在线更新包，包含两种 Linux 架构 |
| `gatehome-SHA256SUMS` | 上述三个包的 SHA-256 校验清单 |

升级前建议停服备份 `config`、`log`、`data`、`sunpanel` 四个完整目录。已有数据升级直接更新即可，无需重新初始化或执行 `init`。
