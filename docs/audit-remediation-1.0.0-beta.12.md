# beta.11 复审问题修复记录

日期：2026-11-10。分支：`develop`。候选版本：`1.0.0-beta.12`。对应 [第二轮审查报告](audit-rereview-1.0.0-beta.11.md) 的 R1–R6。

## 实现

| 问题 | 修复及兼容处理 |
| --- | --- |
| R1 · MCP 仅首页权限不能重启 | 全局保存、独立客户端保存和凭据加载共用 `MCPConfig.hasPermissions()`。有效首页修改权限可以独立存在；没有任何有效权限仍拒绝启用。启动、普通配置更新、备份检查不再漏掉新权限。备份校验错误不再把全部授权错误误报成 DNS 凭据错误。 |
| R2 · 写入响应泄漏其他配置分区 | 没有 read 权限时，配置写入工具只返回 `ok` 和本次保存响应中的 revision。有 read 权限的客户端继续获得原完整脱敏响应，普通网页 API 不变。兼容 Token 与独立客户端都遵守同一规则。 |
| R3 · 账户弹窗焦点逃逸 | 改为原生 `dialog.showModal()`，由浏览器提供模态焦点边界和背景不可交互。关闭后恢复设置按钮、账户菜单触发按钮或命令面板触发按钮；保留密码清空、原账户修改和会话撤销流程。保存期间阻止取消，避免提交与关闭竞争。 |
| R4 · 手机卡片 44px 未生效 | 手机覆盖放在基础规则之后；不改变桌面 38px，手机仍为两列且实际高度 44px。 |
| R5 · 来源字段漏样式 | 给 IPSourceFields 的网卡、IPv4/IPv6 来源和接口列表显式声明 `.form-field`；DDNS 与公网 IP 设置共用组件同时获得修复，不恢复全局 label 排除链。 |
| R6 · 证书冷却提示不一致 | 底层错误移除固定 5 分钟承诺，设置表单说明连续失败的 5 分钟 → 15 分钟 → 1 小时退避；实际可重试时间由任务状态给出，不改变证书申请与 CA 限流逻辑。 |

这些修复不需要重建 SQLite，不修改既有账户、凭据、持久化 ID 或 Token 授权。仅首页修改的全局配置若已经由 beta.11 保存，升级后二进制能直接读取，无需人为扩大查询/配置权限。

## 回归设计

新增 `internal/gateway/mcp_persistence_test.go`，先在修复前确认失败，再验证：

1. 通过真实 `PUT /api/mcp` 保存仅首页权限 → 重新打开原配置 → 普通配置保存 → 加密备份编码/解码；原账户密码哈希保留。
2. 取消最后一项有效权限仍返回 400，直接凭据加载同样拒绝。
3. 兼容/独立客户端 × 仅写/读写四种组合：仅写的配置读取工具被拒绝，写入结果严格只有两个字段；读写客户端保留原响应，revision 精确对应本次保存。

浏览器回归补充：

- 账户弹窗的 Tab / Shift+Tab 不进入背景，程序化聚焦背景侧栏也被模态边界阻止；Escape、取消及设置/菜单/命令面板三个入口恢复焦点。
- 真实账户表单只修改临时账号，原随机密码仍可登录，原会话失效；不操作主实例账户。
- 通过真实全局表单保存仅首页权限，停止临时服务，再用同一目录启动二进制，原账户能重新登录；随后的设置保存保持可用。
- 在 320px 和 390px 直接检查权限卡片计算高度为 44px；检查五个来源字段使用显式类与纵向布局。
- 保留既有普通 HTTP、发现服务、并发冲突、密码清除、流量入口、共享轮询及 Toast 安全区回归。

测试均使用临时目录和随机临时密码，复审中的“确认缺陷存在”探针不作为修复成功的证明。证据保存在忽略目录 `.local/beta12-fixes/`。

## 本机运行

主实例通过现有更新预检与应用流程，从 beta.11 升级到 beta.12。升级前停服复制 config/log/data/sunpanel 四个目录至 `/Volumes/Ti600/GateHomeNewUI/.migration-snapshots/audit-beta12-before-update/`，快照目录权限为 0700。

升级后 API 确认实际版本 `1.0.0-beta.12`。逐项比较业务配置、账户及凭据、MCP 授权、首页 SQLite 表记录摘要均保留；14 条反代、6 条转发和 4 个防火墙未被临时测试修改。只写/仅首页权限组合的验证使用独立配置，不扩大主实例授权。

入口仍为 `http://127.0.0.1:17666/console/`，运行目录仍为 `/Volumes/Ti600/GateHomeNewUI`。ARM64 本机更新包存放在该运行目录的 `releases/1.0.0-beta.12/`，不是公开的双架构发行包。原 Docker 镜像标签仍为 beta.9，受管业务二进制已经更新，实际版本以 status API 为准。

验收摘要为 `.local/beta12-fixes/runtime-acceptance.json`。真实密码仅在钥匙串和鉴权进程中使用，不写入仓库、文档或日志。

## 交付边界

本轮只修复上述六项，不改变已核验正确的可信代理、防火墙和更新包校验。MCP 权限不自动扩大；只写客户端须由管理员提供配置值与 revision。后续公开发行仍需独立的发布操作，此版本先提交 develop 并进行本机候选验收。
