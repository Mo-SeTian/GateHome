# GateHome 1.0.0-beta.10

GateHome 1.0.0-beta.10 重点针对 AI 管理·MCP 权限开关卡片进行了视觉与交互优化，彻底消除了复选框双对勾冗余，保持严整的对称网格设计。

## 🌟 核心改进与修复说明

### 彻底消除 MCP 权限卡片双对勾与冗余复选框
- **精简 DOM 与样式归一**：移除了 `McpPermissions.vue` 组件内多余的自定义复选框占位元素，完全交由全局 Aurora 极客复选框接管，原生 `<input type="checkbox">` 自动呈现高质感蓝紫微光与精致折线对勾。
- **严格对称 2×2 卡片网格**：在移动端保持严格等宽的 2×2 卡片网格（桌面端 4 列平铺），卡片内部左侧单复选框、右侧权限文字单行水平居中，消除长短字参差不齐与多余勾选框问题。
- **保留完整可访问性与语义**：兼容键盘焦点导航、无障碍屏幕阅读器与既有表单双向绑定逻辑。
