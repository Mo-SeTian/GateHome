# GateHome 1.2.0

- **内置托管「代理分流（Mihomo）」模块**：
  - 支持局域网代理服务（Mixed / HTTP / SOCKS / DNS 自定义监听端口与账号鉴权）、可选接管网关出站代理，以及多机场订阅管理（节点过滤、后缀标记、排除自带策略组/规则）。
  - 支持节点单点测速与策略组切换、自定义策略组（兼容 PCRE 正则与扩展字段）、自定义路由规则（支持 `MATCH` 与 YAML 在线编辑）、规则集管理（远程 HTTP / 内置 MetaCubeX 预设 / 手动规则集及批量更新）、GeoIP（`country.mmdb`）管理与统一 `custom.yaml` 增量覆盖校验。
  - 内置「概览」仪表盘、「实时连接」监控（支持一键转自定义规则）、「运行日志」、内核在线更新与 Zashboard 面板；支持配置外部管理 API 局域网/Docker 暴露与管理密钥，方便对接 Neko Master 等外部客户端；完整接入整站加密备份与恢复。
- **安全与稳定性加固**：
  - 加固 Mihomo、WAF / 反向代理、MCP 授权、SSRF 防护、并发控制与 CI 校验链路，拆分并规范后端模块与防御性边界检查。
- **PC 与移动端 UI 布局优化**：
  - 全面修复通知中心、Mihomo 概览、运行态趋势卡片、DDNS 表格、总览趋势栏、公网暴露列表、路由长域名与搜索框等界面的错位、折行、截断及样式泄漏问题。

可在管理台「更新」页面选择「正式稳定版」检查或在线更新到此版本。
