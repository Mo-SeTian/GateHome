# GateHome 1.0.0-beta.23

- 动态域名、SSL 证书任务及 GitHub API Token 增加小眼睛，可在保存后由已登录管理员按需查看原值，默认保持隐藏；仅查看不会修改或重新保存凭据。
- 新生成的 MCP 兼容 Token 和客户端 Token 支持再次查看。原值与验证摘要保存在受权限保护的配置中，并随加密备份保留；轮换与撤销继续使旧 Token 失效。
- 旧版仅保存哈希的 MCP Token 无法恢复原值，重新生成后即可查看。普通配置响应、客户端列表和 MCP 工具不返回已保存原值；查看接口要求管理员会话及请求来源验证，并禁止缓存。
- 统一 Token 输入框的显示、隐藏、读取反馈和手机触控热区；隐藏或关闭编辑器时清理临时回显值，切到后台时自动隐藏。
- 补充凭据查看鉴权、来源验证、日志脱敏、旧 MCP 兼容、持久化和加密备份测试，以及 Token 显隐与不误改凭据的浏览器回归。
