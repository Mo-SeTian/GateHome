# GateHome 1.0.0-beta.15

本次预发行版本（Pre-release）全面完成了旧版本前端代码、废弃动效源码、历史设计原型及关联测试脚本的彻底清理与归档，全量切换并运行在现代 Vue 3 + Vite 控制台上，实现代码库瘦身与架构纯净。

## 主要更新与改进

### 1. 彻底剔除旧版单体控制台前端代码
- **移除旧版静态资源（共 15 个文件）**：
  - 核心逻辑：`internal/gateway/web/app.js` (202 KB)、`index.html` (39 KB)、`style.css` (77 KB)、`ui.css` (58 KB)；
  - 模块脚本：`dashboard.js`、`backup-admin.js`、`mcp-admin.js`、`sunpanel-admin.js`、`context-help.js`；
  - 静态组件与资产：`leibox-ui.js`、`leibox-loader.css`、`icons.svg`、`china-outline.svg`、`icons-LICENSE.txt`、`mcp-sdk-license.txt`；
- **核心依赖安全保留**：
  - `internal/gateway/web/proxy-auth.css`：反向代理密码认证拦截页面（HTTP 401 页面）样式；
  - `internal/gateway/web/mcp-guide.txt`：由 Go 后端直接嵌入并对外提供说明的 MCP 客户端指南。

### 2. 清理废弃动效库与历史设计原型
- **清理旧动效源码**：删除 `internal/gateway/ui/leibox/` 源码目录（6 个文件）及 `scripts/build_leibox.mjs` 构建脚本；
- **清理设计预览文件**：删除根目录下早期用于静态原型评审的 `preview-dawn.html` 与 `preview-modern.html`；
- **清理旧版静态审查脚本**：删除 `scripts/` 下早期针对旧版 `app.js` 的 13 个独立检查脚本（新版已由 `frontend/` 单测与浏览器端端自动化测试完全覆盖）。

### 3. 后端服务精简与纯净路由
- **移除旧版路由**：`internal/gateway/admin.go` 彻底清理 `/legacy/` 路由及旧版静态文件放行规则；
- **统一重定向至现代控制台**：根路径 `/` 默认 307 重定向至 `/console/`，未定义静态路由直接返回 404；
- **地图底图与图标内置**：`china-outline.svg` 迁移至现代前端工程并通过静态路由内置，确保概览大盘与移动端无 404 隐患；
- **构建精简**：`Makefile` 移除旧动效编译命令，保持纯净高效。

### 4. 移动端与通知中心视觉重构
- **消弭双圆点割裂缺陷**：重构 `NotificationCenter.vue`，未读状态由原先与分类圆点并排的浮动蓝点重构为卡片左侧立体边缘高亮指示条（Accent Strip），彻底消除“两个圆点撞车”的排版割裂感；
- **微胶囊分类指示**：消息分类重构成内敛胶囊徽章（微圆点 + 柔和状态色背景），增强视觉层级与移动端阅读体验。
