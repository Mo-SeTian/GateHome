# GateHome 1.0.0-beta.19

- 修复在线更新后控制台继续使用旧版 JS、CSS 的问题。检测到服务版本变化后自动重新加载页面，保留当前访问地址；登录页也会等待服务恢复并同步新界面。
- 更新和回滚均支持版本同步，并防止资源缓存异常导致无限刷新。
- 合入侧边栏的紧凑分组与对齐调整，修正品牌标识的浅色主题样式；移动端导航、关闭和退出按钮采用至少 44px 的触控高度，菜单可独立滚动。
- 增加前后端版本契约及浏览器回归检查，覆盖自动重载、登录跳转和侧边栏在浅色、深色及手机宽度下的交互。

## 从旧版本升级

已打开的 beta.18 及更早版本页面尚不具备自动同步逻辑。首次更新到 beta.19 后，请刷新一次浏览器以加载新控制台；从 beta.19 控制台开始，后续更新会自动加载新资源。

更新会保留现有配置、图标库和上传图片。更新前请确认配置已保存，并保留数据目录及更新前备份。
