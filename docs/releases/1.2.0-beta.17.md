# GateHome 1.2.0-beta.17

- **连接页支持快速加入自定义分流**：
  - 在活跃与已关闭连接卡片底部新增「加入自定义分流」按钮，点击后弹出编辑表单（自动识别根域名 / 子域后缀 / 精确域名 / 目标 IP CIDR / 端口等快捷粒度芯片，提供重复规则提示与 YAML 规则行实时预览）。
  - 保存后自动写入 `config.json` 与 `runtime.yaml` 并弹出重载提示：支持「立即重载配置」（可选同步断开该条旧长连接以立即切换路线），也支持「稍后重载（继续批量添加）」，由顶部待生效提示条一键统一重载。
- **连接页手机端交互与底部抽屉优化**：
  - 手机端（`≤640px`）编辑与重载确认弹窗自动切换为底部抽屉（Bottom Sheet），提供单列 44px 输入控件与拇指区吸底全宽主按钮。
  - 优化手机端顶部控制栏（三等分按钮与全宽双页签）及连接卡片四段式信息布局，底部全宽「加入自定义分流」与独立「断开」按钮防误触且不挤压代理链显示。

可在管理台「更新」页面选择「Beta 测试版」检查更新。
