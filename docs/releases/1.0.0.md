# GateHome 1.0.0

GateHome 1.0.0 正式版以 `v1.0.0-beta.28` 为基线。

- 中文管理台支持浅色、深色和移动端布局，侧栏、登录页与浏览器标签页统一使用新版折页图标。
- 管理台集中管理反向代理、端口转发、动态域名、证书、访问控制和流量统计。
- 图标库支持搜索、导入和批量上传，可为反向代理路由选用图标。
- 内置 SunPanel 支持动态渐变背景、导入反向代理及其图标、自动选择内网地址，以及将在线 SVG 保存为本地图标。
- 提供 Linux amd64、arm64 完整安装包、双架构更新 ZIP 和 SHA-256 校验清单。

已使用 1.0.0 Beta 的实例可在管理台「更新」中选择「正式版」渠道并检查更新。使用 systemd 从不含图标库的旧版升级时，请使用完整安装包同步更新启动器。Docker 部署可用本标签源码重建镜像。
