# GateHome 1.2.0-beta.12

- **代理分流（Mihomo）YAML 编辑器全面升级**：
  - 全新 `YamlCodeEditor` 编辑器接入「配置文件」与「自定义策略组 / 分流规则 YAML 编辑」面板，提供同步滚动行号栏、深浅双主题语法颜色标识（键名、值、字符串/URL、数值、布尔值、锚点、Mihomo 规则类型与策略目标及注释）。
  - 新增当前光标行高亮、2 空格垂直缩进定位线与当前作用域高亮、`Tab` / `Shift+Tab` 缩进及冒号自动缩进辅助，并实时显示当前行列号与缩进层级。
  - 新增前后端一体化错误定位与红行高亮：实时捕获制表符、未闭合引号与流式括号，自动解析后端校验 `line N` 及策略组/规则/端口语义位置，并在错误横幅与底栏提供一键「定位第 N 行」跳转能力。
- **策略组扩展字段全兼容与双向无损同步**：
  - 为 `customGroupYAML` 与 `MihomoCustomGroup` 增加扩展字段保留，完整支持 `icon`、`include-all`、`lazy`、`timeout`、`max-failed-times`、`uselightgbm`、`collectdata`、`sample-rate`、`prefer-asn` 等 Mihomo 扩展属性以及 `smart` / `relay` 组类型。
  - 针对含 `include-all` / `include-all-proxies` / `include-all-providers` / `use` 的动态策略组，合并生成 `runtime.yaml` 时保留 `filter` 原文、不强行填充 `DIRECT`，并在弹窗编辑保存时保留已有扩展字段。
- **PCRE 高级节点筛选正则支持**：
  - 引入纯 Go 正则引擎 `github.com/dlclark/regexp2`（附带 `200ms` 超时保护），支持 `(?=...)`、`(?<!...)`、`(?!...)` 等前后查找及内联标志写法。

可在管理台「更新」页面选择「Beta 测试版」检查更新。
