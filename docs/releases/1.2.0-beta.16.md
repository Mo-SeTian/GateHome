# GateHome 1.2.0-beta.16

- **代理分流新增「概览」仪表盘**：
  - 新增默认「概览」标签页与 `GET /api/mihomo/telemetry` 实时遥测接口，集中展示 Mihomo 运行状态、PID、运行时长、进程 CPU 与物理内存 / Go Heap 占用、宿主机内存对比。
  - 新增近 2 分钟（60 个采样点）实时流量折线图，支持暂停采样、悬停查看逐点速率、当前上下行/峰值及会话累计流量，并提供一键复制监听端口与当前生效配置摘要。
- **Mihomo 内核检查更新与配置备份恢复联动**：
  - 新增 `POST /api/mihomo/core/check-update` 与概览页 /「端口与核心」内核检查更新入口，支持对比 `MetaCubeX/mihomo` 最新发行版并保留配置原地升级热重启。
  - 新增 `POST /api/mihomo/backup` 与 `POST /api/mihomo/restore`，支持 Mihomo 全套配置（`config.json`、`runtime.yaml`、手工规则集）独立导出与恢复，并自动纳入 GateHome 系统全量备份恢复与 WebDAV 云同步。
- **修复手机端排版错位**：
  - 优化规则集卡片、自定义分流规则行与订阅卡片在窄屏下的响应式布局，操作按钮改为底部独立成行，解决文字被右侧操作区挤压竖排的问题。

可在管理台「更新」页面选择「Beta 测试版」检查更新。
