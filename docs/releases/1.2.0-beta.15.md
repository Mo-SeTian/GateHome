# GateHome 1.2.0-beta.15

- **机场订阅支持完全排除自带策略组与规则（仅导入节点）**：
  - 在订阅新增/编辑表单中新增「完全排除机场策略组与规则配置」选项（`exclude_groups_and_rules`），开启后仅导入机场 `proxies`（保留节点正则筛选与统一后缀），忽略订阅自带的 `proxy-groups`、`rules` 与 `rule-providers`，完全使用 GateHome 自定义配置，并在订阅卡片展示「仅导入节点」标签。
- **自定义分流支持并修复 `MATCH` 兜底规则展示与解析**：
  - 后端规则校验、YAML 编辑与配置合成全面支持两段式 `- MATCH,<目标>`（如 `- MATCH,漏网之鱼`），通过弹窗新增 `MATCH` 规则时自动追加至列表底部。
  - 修复自定义分流规则列表中 `MATCH` 规则的展示，显示清晰的「全部剩余流量（兜底）」提示并支持搜索与无障碍标签。

可在管理台「更新」页面选择「Beta 测试版」检查更新。
