# GateHome 1.0.0-beta.21

- 修复局域网 HTTP 页面复制反代域名失败：剪贴板接口不可用或被拒绝时采用兼容复制方式，失败时如实提示，并清理临时输入框。
- 回补 Vue Router 的 Edge 抢焦点修复，移除页面隐藏时触发的历史记录写入，避免最小化后窗口自动弹回；保留离开页面时的滚动位置保存逻辑。
- 动态域名组默认显示紧凑摘要，展开一次即可查看全部域名；支持全部展开或收起、记住各组状态及键盘操作，适配手机和浅色、深色主题。
- 增加真实剪贴板内容、页面隐藏事件及多域名折叠的浏览器回归检查，保留现有页面和业务流程验证。

Linux 安装版若仍使用早于 beta.16 的启动器，请通过完整安装包同步升级启动器和业务程序，以支持图标库引用的备份与后续在线更新。重新安装保留配置、日志、数据和 Sun-Panel 目录。
