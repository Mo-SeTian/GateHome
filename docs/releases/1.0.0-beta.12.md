# GateHome 1.0.0-beta.12

修复 beta.11 第二轮审查确认的六项问题，重点补齐 MCP 授权持久化与响应权限边界。

- 全局 Token 仅授予首页修改后，可以正常重启、继续保存配置和检查备份；仍拒绝启用无有效权限的授权。
- 无查询权限的 MCP 配置写入只返回成功状态与 revision，避免返回其他配置分区；读写客户端保留原响应。
- 管理员账户改用原生模态弹窗，约束键盘焦点、阻止背景操作并恢复触发按钮焦点，保留账户修改后的退出重登。
- 手机 MCP 权限卡片实际高度修正为 44px，IP 来源字段统一布局，证书错误与界面说明采用真实退避策略。

沿用现有配置、SQLite、账户与凭据。新增持久化/权限组合回归及真实浏览器重启、账户保存和多宽度检查。详见 [修复与验收记录](../audit-remediation-1.0.0-beta.12.md)。

本版本为 develop 候选构建，本机主实例已升级并验证原数据保留，尚未创建 GitHub 发行版。
