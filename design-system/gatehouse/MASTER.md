# Gatehouse 0.0.15 界面与交互规范

设计沿用用户选定的第二版配色与全局导航，内容区按后续要求改为可折叠分组。使用 ui-ux-pro-max 的组件、间距与可访问性规则，以及 spt-interaction-motion 的可中断转场。技术栈保持 Go embed + 原生 HTML/CSS/JS，不增加外部字体或动画框架。

## 页面结构

各个管理页面各自保留路由与职责。首页为概览；设计展示板中的反代、手机编辑和统计示例属于不同页面。

反代页保留 184px 全局导航；每个组占内容区一行，统一面板框住组内规则，独立收起 / 展开。取消组侧栏和右侧编辑区，所有宽度均使用原生模态窗口，680px 以下全屏编辑。编辑器开闭不修改配置，保存成功才提交结果。请求进行中暂停开启其他编辑项，防止删除后旧列表索引指向其他服务。

所有宽度均在页头显示“添加反代组”，每组标题保留“添加代理服务”。手机操作至少 44px 高。DDNS 组、防火墙策略和证书任务共用独立分组折叠；收起后保留摘要、状态与编辑入口。折叠状态在页面切换和刷新数据时保留，本次会话结束后重置；保存代理服务后展开所属组。

SSL 页的邮箱、签发环境、自动申请和条款选项集中于“证书配置”弹窗；每个证书任务为一个可折叠面板。全局设置只在配置弹窗编辑，任务详情仅显示其当前环境。

## 视觉与组件

- 主色 `#4256d5`、悬停 `#3447ba`；工作区 `#f6f7fa`；白色表面；正文 `#252c3e`；次要文字 `#667085`；边界 `#e2e6ee`。
- 成功、警告、危险各自保留语义色与文字；正常流量图表使用 `#22825b`，图例与曲线一致。
- 系统中文字体；IP、域名和端口使用等宽字体，读数使用等宽数字。标题 24–28px，面板标题 16px，控件与正文 13px，说明 12px。
- 桌面操作与输入至少 40px，手机至少 44px；状态标签至少 24px，不当作操作按钮。手机输入字号 16px。
- 页面间距 24px，面板内边距 24px，手机外边距 16px；面板圆角 10px，按钮 7px，输入 8px。
- Tabler Icons 3.49.0，24px 网格、2px 线宽，SVG symbol 本地加载。装饰图标隐藏于辅助技术，图标按钮提供名称，许可证随源码保留。
- 分组标题使用 34px 类别图标底块与 16px 折叠图标；展开朝下、收起朝右。编辑、删除、启停、筛选、保存、分页、外链统一为 SVG，按钮保留文字；外链补充新标签页说明。登录与冻结提示使用相同图标形态，禁止把 Unicode 字符当作操作图标。
- 标题与状态同组，操作区单独对齐。反代协议、防火墙、访问账号和运行状态各占一列。所有破坏性操作使用危险语义。
- 桌面表格统一表头、行间距和操作对齐；手机变为保留字段名的列表，IPv6、长规则名和日志路径换行展示。统计图表适配容器，不扩大页面宽度。
- 编辑表单共用固定标题、可滚动内容和固定底部按钮。所属组、子域名 / 访问域名和完整域名预览置于表单前部，始终展开；保存或离开空域名字段时显示字段旁的提示并关联辅助技术，填写后清除；独立服务账号明确与管理员登录分开，密码不回显。

## 动效与输入

| 状态 | 交互和提交 | 完成与中断 |
| --- | --- | --- |
| 页面切换 | 路由立即更新，透明度和 Y 8px 入场 | 240ms；新导航取消旧动画；后台刷新不重复入场 |
| 编辑打开 | 所有宽度原生模态并约束焦点 | 240ms；从当前状态接管，不丢失正在编辑的字段 |
| 编辑关闭 | 取消 / Esc 不保存；成功提交后关闭 | 140ms；旧退出不能关闭重开的编辑器；恢复触发按钮焦点 |
| 按压反馈 | Y 1px，保留按钮布局尺寸 | 100ms；释放恢复 |
| 数值更新 | 实际值立即显示，局部透明度反馈 | 160ms；仅变化的读数动画 |
| 请求进行中 | 禁用重复提交、aria-busy；失败保留表单 | 完成恢复操作；统计保留有效结果，新请求优先 |
| 手机导航 | 抽屉打开使主区 inert，Tab 循环；选择目标后切页 | 240ms；Esc 与遮罩取消并恢复焦点 |
| 分组折叠 | hidden 与 aria-expanded 立即同步；折叠图标旋转，展开内容淡入 | 160ms；反向操作取消旧动画，键盘 Enter / Space 与指针一致 |

减少动态效果时跳过位移与缩放，保留加载和结果语义。菜单支持键盘打开和 Esc 关闭。长弹窗内滚动不影响标题与按钮；保存不会回显或覆盖留空的已存密码。

`node --check internal/gateway/web/app.js`、`node scripts/frontend_checks.mjs`、`node scripts/motion_checks.mjs`、`node scripts/security_checks.mjs`、`make test`。

## 0.0.17 记录查询

防火墙拦截记录使用独立页面，统计保留指标及独立分页的最近安全事件。两个记录列表复用同一筛选与分页组件，状态分别保存；筛选按钮提交，翻页沿用已应用条件及快照。刷新保留旧结果，失败后展示可聚焦的错误，翻页聚焦结果摘要。来源 IP 为独立字段，下方为离线估算归属地；手机保留字段名、44px 控件与长 IPv6 换行。


## 0.0.18 服务发现

- 复用配置弹窗、按钮、图标、状态和既有弹窗动效。桌面最大宽 860px；手机全屏，固定标题 / 动作区。原生验证只允许滚动内容区。
- 扫描进度逐条追加结果，保留勾选、服务名和子域名输入；关闭取消未完成任务，旧响应不得覆盖后续弹窗。
- 子域名始终可见，显示完整域名预览，提交时在字段旁显示必填、格式或重复提示。结果图标有固定尺寸，失败回退到本地图标。
