# 统一防火墙配置说明

0.0.16 在原防火墙中加入 Coraza 3.8.1 与内嵌 OWASP CRS 4.25.0。规则随程序发布，运行时不从外部下载规则。升级保留原 IP 规则、订阅、账号验证和冻结记录；旧配置的新增防护默认关闭。

## 配置入口

进入 **防火墙管理 → 添加 / 编辑防火墙**，设置 IP 规则、Web 攻击防护、HTTP 规则、限速和冻结，再到 **反向代理 → 编辑代理服务** 绑定该防火墙。多个服务可以共用策略，计数仍按服务和实际连接 IP 隔离。只需要 Web 防护时可不添加 IP 组，并将 IP 未命中动作设为允许。

配置保存前会验证表达式并编译 CRS；失败保留表单，原配置和运行策略继续使用。成功保存立即生效。无关配置保存会复用已有 WAF 与计数，修改防护策略会重新建立该策略的计数。

## Web 攻击防护

| 配置 | 行为 |
| --- | --- |
| 关闭 | 不运行 CRS；HTTP 规则、限速仍按各自设置执行。 |
| 仅记录 | 攻击命中写入日志与统计，继续转发；不会因为检测命中自动冻结。 |
| 拦截 | 达到 CRS 入站异常分数阈值 5 或触发直接拒绝规则时拦截，通常返回 403。 |
| 检测等级 | PL1–PL4；建议从 PL1、仅记录开始，确认正常请求后开启拦截。更高等级需要更多误报调优。 |
| 请求体检查上限 | 默认 1024 KiB，可设置 64–32768 KiB。拦截模式超限返回 413；仅记录模式记录“未完成检查”并转发完整请求体。 |

CRS 检查请求方法、URI、请求头及上限内的请求体，包含 SQL 注入、XSS、路径穿越和已知扫描器等规则。正常 JSON、文件上传、WebSocket 升级和流式响应有回归测试。响应内容和 WebSocket 升级后的消息不检查；未完成检查不等于请求安全。读取或解析发生不可处理的错误时会拒绝请求；资源繁忙返回 503，不能因此绕过检查。

上传较大的服务应调整检查上限。并发检查和请求体内存有全局容量限制，较大上限会降低可同时检查的上传数量。每次请求体检查最多读取一分钟。

## 规则例外

从 **防火墙拦截记录**（或 **统计 → 最近安全事件**） 找到实际 CRS 检测规则编号，添加对应例外。编号范围 911000–948999；不能豁免最终异常评分拦截规则。

- **服务域名**：精确匹配，不填写则作用于使用本防火墙的所有服务。
- **路径前缀**：必填，`/api/upload` 同时匹配以该字符串开头的路径，请选择足够具体的前缀。
- **参数名**：填写时只排除该规则对这一参数的检查；留空则排除匹配请求中的整条规则。

例如某服务的 `/api/search` 参数 `q` 误触发 `941100`，可限定该域名、路径和参数；其他参数、路径和规则继续检查。例外中的路径和参数限制为界面提示的安全字符，不接受任意 SecLang 指令。

## 爬虫、HTTP 规则与限速

HTTP 规则按顺序检查 User-Agent、已解码的请求路径或请求方法，使用 Go 正则语法，支持 `(?i)` 忽略大小写。动作可以是拦截或仅记录；拒绝规则命中立即返回 403。最多 50 条自定义规则、50 条 CRS 例外。

示例：User-Agent 表达式 `(?i)(examplecrawler|examplescanner)` 可拦截对应示例客户端。客户端可以修改 User-Agent，因此它不构成可靠的身份验证，建议结合访问限速。此版本没有浏览器挑战或行为识别功能。

限速按 **服务 + 实际连接 IP + 路径前缀** 使用固定时间窗口，默认界面值为 60 秒内允许 120 次。超限返回 429，并携带 `Retry-After`。不信任客户端的 `X-Forwarded-For` 等来源头；前置代理会使 Gatehouse 看到前置代理的地址。

## 自动冻结、账号与处理顺序

防护自动冻结默认界面值：累计窗口 300 秒、5 次拦截、冻结 60 分钟。WAF、HTTP 规则和限速分别累计；一次请求命中多条 CRS 规则只算一次。仅记录命中、请求体超限与资源错误不触发自动冻结。计数在内存中，重启清零；已经生成的冻结记录持久化保存。

独立访问账号的失败次数仍在代理服务编辑窗口设置，默认 5 次 / 60 分钟，账号与管理员账号分开。两类冻结在 **IP 拦截名单** 中统一管理，显示来源、原因、反代规则及起止时间，可以提前解冻。安全冻结解冻时同时清除该服务 / IP 的防护计数。

请求依次通过：域名路由 → 现有 IP 冻结 → IP 组与订阅 → HTTPS 限制 → HTTP 规则及限速 → 独立服务账号 → CRS → 后端。IP 允许与正确账号不会跳过 CRS；服务登录页由现有账号验证机制处理，访问密码不送入 CRS。

## 统计与隐私

从 0.0.17 起，**防火墙拦截记录** 独立显示每次请求的检测规则、异常分数与严重性，支持分页和组合筛选，包含仅记录命中。**统计** 保留 WAF 命中 / 拦截、HTTP 规则与限速拦截等请求指标，并为最近安全事件提供独立分页和筛选。汇总请求指标对同一请求去重，指标不能直接相加。仅记录事件明确显示已放行。

**反代日志** 支持按检测引擎、规则编号和规则名称搜索。保存静态攻击类别、规则编号、动作、分数与严重性；不保存请求正文、参数值、Coraza 展开的匹配信息或原始审计日志。已有日志的路径与凭据脱敏继续执行。
