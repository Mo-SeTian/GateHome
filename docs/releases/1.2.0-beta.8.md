# GateHome 1.2.0-beta.8

- **修复运行日志与配置文件字符间距过宽**：移除导致数字 `0`–`9` 与日期/小数点按 Emoji 宽度渲染的 `font-variant-emoji: emoji` 属性，同时保留 `--mono` / `--sans` 彩色 Emoji 与中文字体回退链，使日期时间、版本号及倍率和 `⚓`、`♻️`、`🚀` 等符号均可紧凑清晰显示。
- **新增「连接」实时监控页面**：在「代理分流」新增「连接」页签，2 秒实时轮询 Mihomo 活跃与已关闭连接，展示客户端源 IP/端口、目标域名与端口、实时上传下载速率、累计流量、命中规则与代理链最终出站节点；支持按协议与节点筛选、多关键词搜索、断开单条连接与「关闭所有活跃连接」。
- **自定义规则新增规则集 (`rule-providers` + `RULE-SET`) 支持**：在「自定义分流」支持远端 HTTP、14 个内置精选 MetaCubeX 规则集及手动编写三种来源，支持 `YAML` / `TXT` / `MRS` 格式、自定义存储路径、刷新间隔与匹配模式（`domain` 域名 / `ipcidr` IP 网段 / `classical` 混合），新建时可一键生成对应的 `RULE-SET` 分流规则。
- **新增合并前「自定义配置 (`custom.yaml`)」总览与编辑**：在「配置文件」页签中新增 `custom.yaml` 视图，集中展示与编辑全部自定义策略组、规则、规则集、专线 DNS 及额外覆写键（如 `find-process-mode`、`sniffer`、`hosts`），与各页面配置双向实时同步；每次更新机场订阅均完整保留并以自定义配置覆盖冲突项。

可在管理台「更新」页面选择「Beta 测试版」检查更新。
