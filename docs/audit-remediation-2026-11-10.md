## 数据与授权兼容

- 旧 Token 缺失 `sunpanel_write` / `security_write` 时，保留原 `write` 授权范围，不强制撤销或重新生成。
- 新版界面保存显式布尔值，新建客户端默认查询权限。旧客户端省略新增字段更新已有授权时，服务端保留已经保存的显式限制，避免将 false 改回继承权限。
- 独立客户端的 Sun-Panel 用户 ID 为 0 仍表示不授权首页，不能继承兼容 Token 的账号。
- `trusted_proxies` 默认空，既有部署继续使用连接 IP。仅影响 HTTP 反代的日志、防火墙、限速和冻结；管理登录及 TCP/UDP 不读取转发头。
- 当前版本的配置持久化及加密备份保留新增字段，同时验证原管理账户不变。手动降级到旧程序时，旧程序不识别新增授权限制；应先停用受限客户端。内置回滚会同时恢复历史配置和授权。

## 验证范围

正式回归覆盖：新增凭据脱敏、满载计数回收及未过期保护、超限表单攻击与截断 JSON 检测、非法上游的原子重载、会话淘汰、备份期间快速反馈、可信代理链/多 IP 冻结隔离、配置与备份保留、MCP 独立权限/旧客户端保存/账号隔离、DDNS 并发与触发合并、证书退避。

前端单测 33 项，包括慢请求不重叠、隐藏暂停、重新可见刷新及异常后继续轮询。真实浏览器回归使用随机临时账户、临时数据目录、普通非安全 HTTP 源和本机上游，验证：

- 七类新增编辑器、真实反代保存、域名前缀、TLS 默认值、密码清除、流量入口、服务发现和并发冲突。
- MCP 新客户端默认权限、首页/安全策略分离、真实创建和再次编辑保存。
- 可信代理 IPv4/IPv6 配置保存及清除。
- 订阅页 11 秒内状态请求最多两次，慢响应完成后再调度；隐藏期间不发送状态请求，重新可见立即刷新。
- 320/390px 的七类编辑器不超出视口，手机权限网格保持两列。
- 模拟安全区 top=44、bottom=34、left/right=12，真实 Toast 的长文本框保持在可用区域内。

安全区通过 Chromium [DevTools Protocol 的 SafeAreaInsets override](https://github.com/ChromeDevTools/devtools-protocol/blob/master/json/browser_protocol.json) 模拟，不将其当作物理 iPhone 测试。`.local/audit-verification/` 保存本轮测试日志和截图，不进入发行包。

Go 全量普通测试、全量 race、DNS 三项各 100 轮 race、go vet、Vite 生产构建及 macOS/Linux ARM64 单二进制构建均通过。日志分别为 `fixes-go.log`、`fixes-go-final.log`、`fixes-browser-final.log`、`fixes-unit-final.log`、`fixes-vite-final.log` 和 `fixes-build-final.log`。

补充 Linux 真实子进程冒烟：在独立目录复制首页 SQLite 数据，使用候选二进制启动真实 Sun-Panel worker，为临时客户端授予首页修改并绑定账号，确认 MCP 新建分组实际写入隔离数据库，同时网关配置写入被拒绝。测试后删除临时容器和目录，原首页数据库不作修改。结果见忽略目录中的 `linux-smoke-result.json`。

## 仍需按部署条件处理的边界

同主机名不同端口 Cookie 不隔离的历史风险，需要使用独立管理主机名与 HTTPS，并保证同名服务可信；设置页补充了对应说明。本轮不将改 Cookie 名称、放宽来源校验或直接信任所有私网当作修复。

请求体前缀检查不保证完整 JSON/上传内容的检测覆盖；高流量达到计数容量、备份停首页子进程和程序升级仍可能短暂返回不可用。新授权范围由当前程序执行，不能要求旧二进制识别这些字段。

本轮使用本机模拟数据及临时账户验证，没有对真实公网 DNS/CA 发起写入，也没有执行持续大流量攻击或物理设备测试。
