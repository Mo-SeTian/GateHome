# GateHome 1.0.1-beta.8

- 「观察与管理 → 运行状态」汇总 CPU、内存、反代健康和管理员登录会话。监听清单列出 GateHome 实际占用的管理台、反代组、SunPanel 独立入口与内部桥接，以及各 TCP / UDP 转发端口。
- 点击任意反代可展开近 15 分钟、30 分钟或 1 小时的连通性历史。绿色表示可达，红色表示失败，灰色表示该分钟没有采样。记录按已有健康检查间隔逐步积累。
- 「通知中心 → 故障推送」支持 Webhook 和 WxPusher。通过 AppToken 与已订阅应用的 UID 配置 WxPusher，可选择反代上游异常、WebDAV 备份失败及正式证书即将到期三类告警，并发送测试通知。持续故障只生成一条告警，恢复时再次通知。

本版本为预发行版。可在管理台「更新」中选择「Beta 测试版」渠道检查更新。
