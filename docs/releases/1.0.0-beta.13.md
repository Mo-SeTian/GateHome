# GateHome 1.0.0-beta.13

本次预发行版本（Pre-release）全面升级了 GateHome 品牌视觉标识体系，落地了 macOS 级别的即时通知系统与全功能通知管理中心，并重点优化了动态域名界面的收展折叠体验与表格边框渲染。

## 主要更新与改进

### 1. 全新品牌视觉标识（方案 A · 极光星门 Aurora Portal）
- **全新矢量 Logo 设计**：融合「虫洞星轨」、「居所穿透光拱」与「核心脉冲信标」，精准传达家庭居所连接全球私有云、穿越网络边界的极客网关概念。
- **全端与双主题适配**：
  - 登录主界面（`LoginView`）与侧边栏常驻头标（`Sidebar`）全量同步换新；
  - 完美适配深色极客黑（Dark）与晨曦清透白（Light）双主题色彩自适应；
  - 新增标准 `favicon.svg`，浏览器标签页与 Apple Touch Icon 实现像素级微型图标高清晰度渲染。

### 2. macOS 风格即时通知与全功能通知中心（Notification Center）
- **轻量即时 Toast 浮窗**：
  - **电脑端**：38px 单行超紧凑 macOS 毛玻璃胶囊，带发光状态点、分类徽标、消息提要、悬停暂停倒计时与独立圆圈 `✕` 关闭按钮；
  - **手机端**：右上角微型双行卡片（宽仅 215px，避开手机顶栏安全区），不横向占满整屏，兼顾信息呈现与操作低侵入；
  - 点击消息主体可智能路由跳转至相关业务配置页面（如 WAF 防护、DDNS、备份等）。
- **全功能通知管理中心**：
  - 顶部导航栏右侧新增 `🔔` 铃铛按钮与未读消息红色脉冲数字徽标；
  - 电脑端点击呼出 360px 高透毛玻璃右侧抽屉，手机端呼出 78% 弹性底部抽屉（Bottom Sheet）；
  - 支持「全部已读」、「一键清空」、分类筛选 Tab（全部 / WAF 防护 / DDNS / 系统备份 / 其它）、单条删除及快捷配置跳转；
  - 历史记录自动持久化保存在 `localStorage`（上限 60 条），登出时安全联动收起。

### 3. 动态域名（DDNS）双层折叠优化
- **组卡片独立折叠**：各 DDNS 配置组卡片头部支持一键点击折叠，折叠后收起为 44px 摘要栏（展示组名、解析数量、状态与旋转箭头），节省 80% 垂直高度；
- **状态本地持久化**：使用本地存储自动记录各组折叠/展开习惯，刷新不丢失；
- **全局总控**：顶部操作栏提供「展开全部组 / 收起全部组」快捷按钮；
- **长域名列表局部收折**：组内解析域名超过 6 条时，默认展示前 5 条并提供局部展开开关，杜绝长表格占满视口。

### 4. 界面细节与纯净度优化
- **表格边框阴影清除**：彻底清理 `.report-table-wrap` 之前残留的左右渐变投影，还原干净透明的磨砂发丝边框质感；
- **安全与架构审查文档**：归档完整的安全与架构审查报告 `docs/security-and-architecture-audit-1.0.0.md`。
