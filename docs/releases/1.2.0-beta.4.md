# GateHome 1.2.0-beta.4

- **单节点单独测速**：在策略组节点卡片右侧点击任意非内置节点的延迟数值（如 `—` 或 `52 ms`）即可单独探测该节点延迟（`POST /api/mihomo/node-delay`），并返回实时耗时或明确提示超时。
- **嵌套策略组测速回退**：策略组测速不再跳过内部引用的子策略组（如「自动选择」），可随整组或单独测速一并更新延迟。
- **启动/停止状态自动持久化**：通过顶部「启动」或「停止」控制 Mihomo 内核后，自动同步保存随 GateHome 启动运行配置（`enabled`），在线更新重启后自动恢复运行。
- **离线状态明确提示**：内核未运行时界面标记为「离线预览（请先启动内核）」，悬停测速控件提示需先启动内核。

可在管理台「更新」页面选择「Beta 测试版」检查更新。
