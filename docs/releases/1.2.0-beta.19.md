# GateHome 1.2.0-beta.19

- **前端 PC 与移动端 UI 布局全面优化修复**：
  - **通知中心（移动端）**：修复筛选区在窄屏下被异常拉高产生大段空白的问题，恢复紧凑排布并修正搜索框左侧多余留白。
  - **Mihomo 概览（移动端）**：优化 KPI 标题与累计流量项换行规则，避免标题文字垂直竖排及统计文本碎片化折行。
  - **运行态监控（移动端）**：修复趋势卡片统计摘要被强制省略截断的问题，允许自适应换行以完整展示峰值与均值。
  - **动态解析 DDNS（移动端）**：优化记录表格列宽与 IPv4/IPv6 地址列不折行策略，避免 IP 地址被拆断换行。
  - **总览页趋势模块（移动端）**：限定 2+1 按钮网格作用域至页面主标题栏，让「24 小时访问趋势」顶部两枚按钮保持对称等宽排列。
  - **公网暴露与安全设置（移动端）**：为暴露列表补充合理最小宽度并防止入口地址按字符碎裂断行。
  - **路由列表与搜索框（PC / 移动端）**：优化长域名卡片的单行省略展示（悬浮保留完整 URL 提示），并修正全局 `.search-box` 规则误伤 Flex 搜索框导致的内边距偏移。

可在管理台「更新」页面选择「Beta 测试版」检查更新。
