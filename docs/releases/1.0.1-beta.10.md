# GateHome 1.0.1-beta.10

- 重设计「观察与管理 → 通知中心」：新增概览统计卡与流式事件卡片，支持按阅读状态、分类及关键词检索通知，区分服务端持久记录与本机提示；故障推送页新增渠道队列与订阅状态卡片，并在 Webhook 模式提供请求体格式参考。
- 重设计「观察与管理 → 运行状态」：展示主机运行环境与活动网卡收发速率、CPU/内存阈值进度条，支持暂停/恢复 10s 自动同步；反代上游连通性新增异常/正常/未绑定筛选与关键词搜索，逐分钟历史改用自适应竖条阵列并计算时段可用率与平均耗时；监听端口支持按反代组、端口转发、管理分类及 TCP/UDP 协议筛选。
- 优化 `320px` 与 `390px` 移动端排版，消除窄屏横向溢出与错位。

本版本为预发行版。可在管理台「更新」中选择「Beta 测试版」渠道检查更新。
