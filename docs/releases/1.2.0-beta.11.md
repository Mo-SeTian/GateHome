# GateHome 1.2.0-beta.11

- **代理分流（Mihomo）模块拆分与日志脱敏增强**：
  - 将原 `mihomo_process.go` 按职责拆分为 `mihomo_validate.go`（YAML 校验）与 `mihomo_install.go`（内核、Zashboard 与 MMDB 下载安装），统一复用 `encodeYAMLIndent2` 2 空格缩进序列化并移除冗余请求体限制。
  - 扩展 `mihomoLogRing` 日志脱敏规则，补充拦截包含 `authorization:`、`bearer `、`password=`、`pass=` 的敏感行并新增对应单元测试。
- **后端防御性边界加固**：
  - 为维护恢复 ZIP 的 `password` 表单读取、Beta 版更新检查 GitHub API 分页、ICO 图标尺寸读取、HTTPS 服务发现证书链解析、端口转发 TCP `CloseWrite` 断言及 AI 助手配置保存接口补齐边界防护与安全校验。
- **前端公共工具收敛与构建发布卫生优化**：
  - 抽取通用剪贴板复制模块 `clipboard.js`（兼容 HTTP 降级与焦点恢复），统一收敛 `formatBytes` 字节格式化与公共 `.switch` 样式，移除未使用的 `vite-plugin-singlefile` 依赖。
  - 为默认构建补充 `CGO_ENABLED=0`、为 `Verify embedded console` 工作流增加并发取消策略并精简 `.dockerignore` 测试上下文。

可在管理台「更新」页面选择「Beta 测试版」检查更新。
