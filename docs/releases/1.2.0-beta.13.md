# GateHome 1.2.0-beta.13

- **代理分流（Mihomo）规则集 / 订阅集批量更新与规则数统计**：
  - 新增 `GET /api/mihomo/rule-sets/stats` 与 `POST /api/mihomo/rule-sets/update` 接口：Mihomo 内核运行时从 `/providers/rules` 实时获取所有规则集（含 `.mrs` / `.yaml` / `.txt`）的规则数量与更新时间，未启动时自动回退统计手动或本地磁盘规则条数。
  - 在「规则集」页签顶部与卡片上展示每个规则集的规则数量、汇总总数及更新时间，支持一键「批量更新」全部已启用远端/内置规则集，并支持单条规则集独立即时更新。
- **「自定义分流」顶部操作栏布局固定一致**：
  - 将 `[分流规则 | 规则集 | YAML 编辑]` 切换控件固定锚定在工具栏左侧并与「配置文件」页签对齐，确保在三个子视图之间切换时位置与高度完全保持一致，不再左右跳动；右侧统一承接筛选栏、「批量更新」及新建操作按钮。

可在管理台「更新」页面选择「Beta 测试版」检查更新。
