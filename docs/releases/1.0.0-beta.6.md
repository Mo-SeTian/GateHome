# GateHome 1.0.0-beta.6

GateHome 1.0.0-beta.6 是一次全面的移动端体验与界面细节优化版本，针对手机端及触屏场景在实际数据下的使用体验进行了全面审查与系统性重构，修复了 9 项影响移动端浏览与交互的关键问题。

## 🌟 核心改进与修复说明

### 1. 手机端顶栏控制区图标统一尺寸与精准对齐
- **统一几何尺寸**：在移动端屏幕（≤1023px 及 ≤600px）下，将网关状态胶囊（转为 32×32px 正圆运行指示灯）、深浅色外观切换按钮（32×32px）与管理员头像下拉菜单（固定高度 32px）严格统一基线对齐。
- **杜绝文字隐藏后椭圆扁平畸变**：隐藏状态文字后指示灯保持正圆居中，各控件间距统一为 8px，视觉比例工整紧凑。

### 2. 移动端 SunPanel 浏览器首页服务表单重构
- **消除横向溢出截断**：移除首页服务表单外部嵌套的报表表单网格，重构为 `.sunpanel-form` 流式表单与自适应 `.form-grid`。
- **单列响应式流**：在 ≤768px 下自动从 3 列转为整齐单列，端口、内网访问地址、外网访问地址 100% 宽度垂直流式排列，彻底消除向右溢出屏幕截断的严重错位。

### 3. 弹窗移除自动拉起输入法（Autofocus 治理）
- **触屏交互守护**：全面移除反代路由、DDNS 组、证书域名、防火墙策略、端口转发、IP 拦截名单等所有模态弹窗表单中输入框的原生 `autofocus`。
- **防止误遮挡**：杜绝移动端用户每次打开添加/编辑对话框时瞬间被强制拉起系统软键盘遮挡弹窗画面的恶劣体验。

### 4. 手机端状态徽章撑满整行修复
- **防拉伸约束**：全局给 `.badge` 增加 `width: fit-content !important; max-width: 100%; flex-shrink: 0; white-space: nowrap;`。
- **卡片内头部隔离**：在 `reports.css` 移动端媒体查询（≤640px）中，精确限定卡片内头部 `.report-panel .report-heading, .ddns-card .report-heading` 保持 `flex-direction: row`，彻底根治卡片内“执行成功”、“已启用”等状态徽章被拉伸成整行大色块的问题。

### 5. 顶栏操作与卡片内部按钮排布规范
- **AI 管理 / MCP 页面**：为卡片内部操作按钮统一封装 `.form-actions`，高度规范为 38px；顶栏按钮在 ≤640px 下两等分对称分布（各占 50%）。
- **概览页面**：顶栏「刷新数据」、「配置组件与顺序」、「管理反向代理」在 ≤767px 下采用 2 等分网格 + 主操作全宽跨列排布，规避单边空白。

### 6. 日志与统计分页栏每页条数下拉框尺寸异常修复
- **结构重构**：在 `LogExplorer.vue` 分页器中拆分出独立控制器行 `.pagination-controls-row`、标签 `.pagination-size-label` 与下拉框 `.pagination-select`。
- **严格固定尺寸**：强制限定分页下拉框宽度为 `88px`、高度 `32px`、单行行高 `30px`，杜绝全局 select 样式的 100% 宽度撑爆破坏布局。
- **移动端对称分布**：在 ≤768px 下，上方居中显示总记录数，下方左侧为每页条数，右侧为上一页/下一页，两侧平衡对称。

### 7. 安全事件明细筛选项重置与刷新按钮混淆修复
- **明确文本提示**：为重置按钮补全汉字 `<RotateCcw :size="13" /> <span>重置</span>`。
- **网格对称分布**：在移动端下与【筛选】、【更多筛选】、【刷新】共同构成 4 按钮网格对称排布，彻底消除两处旋转箭头被误认为“重复刷新”的困扰。

### 8. 系统与访问日志同步继承分页与按钮修复
- `LogsView`（系统与访问调用日志）与 `StatisticsView`（统计与安全事件明细）共享重构后的 `LogExplorer`，全面同步获得收起/展开抽屉、固定尺寸分页器及对称按钮布局。

### 9. 移动端登录界面输入框图标与文字重叠彻底根除
- **输入框左右内边距锁死**：在 `LoginView.vue` 和 `form-tokens.css` 中双重声明 `.input-with-icon input { padding-left: 38px !important; padding-right: 42px !important; }`。
- **文字与图标严格隔离**：确保管理员账号（User 图标）与密码（Lock 图标）与 placeholder / 输入文字始终保持至少 12px 的呼吸间距，杜绝重叠。
