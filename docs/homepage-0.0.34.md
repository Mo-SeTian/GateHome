# GateHomePage 管理与数据迁移

GateHome 的“浏览器首页”管理服务开关、端口以及 Page 账号。开启或变更端口后重启服务，已有桌面内容保留。分组、页面、应用和外观都在 Page 自身管理。

GateHome 管理员可在自己的 Page 桌面使用现有管理员账号登录。在 GateHome 添加的 Page 账号只能使用首页，无法访问 GateHome 管理配置、维护功能、管理账号或其他用户的私有桌面。账号修改、密码重置和停用统一在 GateHome 完成；修改或停用后，此账号的 Page 会话立即失效，桌面内容保留。

首次登录新账号会进入独立空桌面。右上角“编辑”显示添加分组、分组设置、页面管理、添加应用、反代导入、组件和桌面设置。编辑模式中点击应用即可打开编辑弹窗，也可使用卡片下方编辑、删除按钮。删除需要确认，随后可通过“撤销删除”恢复最近一次删除；再次保存其他修改后，撤销入口清除。“完成编辑”恢复普通应用访问。

每组可以维护多个页面。页面设置包含每页行数、桌面列数和手机端最多列数；超出容量自动产生圆点续页。圆点、键盘、触摸滑动、鼠标滚轮和鼠标左右拖动仍可翻页。编辑模式中鼠标拖动不会与应用编辑按钮竞争。

应用支持名称、描述、置顶、页面内位置、所属页面、内网链接、外网链接和图片。内外网至少填写一项，只允许不含账号密码的 HTTP / HTTPS URL。图标可上传或通过 URL 获取，支持 PNG、JPEG、GIF、WebP、ICO，最大 5 MiB；位图重新编码至最长 128 像素。背景最长 2560 像素，保存为 JPEG。图片由服务器保存到当前用户目录，用户之间的图片读取也隔离。

“组件”可以添加或移除时间日期与网页搜索。搜索引擎、背景、遮罩、紧凑卡片、链接地址显示以及自定义 CSS 均在“桌面设置”维护。自定义 CSS 最多 32 KiB，只作用于当前桌面；网页禁止外部脚本、字体、样式和图片请求。开启“允许访客查看此桌面”后，持有该桌面链接的访客可以查看应用名称和配置的内外网地址，编辑仍需此桌面的账号登录。普通用户无法通过修改链接参数切换到其他用户的编辑配置。

“从 GateHome 导入”只读取服务名称、图标及内外网地址，不返回 DNS 凭据、反代验证密码、防火墙配置或管理密钥。选定服务导入后成为独立应用，图标也复制到用户自己的目录；随后修改反代规则不会覆盖桌面内容。目标页面中地址相同的应用不会重复导入。

数据目录如下，管理员桌面使用固定 `admin`，其他用户使用系统生成的用户 ID：

```text
/config/state.json                 # GateHome 配置、首页开关端口、账号密码哈希
/data/page/admin/config.json       # 管理员桌面内容、组件、CSS、独立修订号
/data/page/admin/route-images/     # 管理员桌面图标
/data/page/admin/homepage-backgrounds/
/data/page/<用户ID>/config.json
/data/page/<用户ID>/route-images/
/data/page/<用户ID>/homepage-backgrounds/
```

Linux 默认根目录为 `/etc/gatehome`，对应 `data/page/`。Docker 映射现有 `/data` 后即可在宿主机映射目录中看到 `page` 文件夹，无需额外挂载。重新安装时同时保留 `/config`、`/log` 和 `/data`，账号、桌面、图片和日志才能完整恢复。浏览器的分组、页码、网络和搜索引擎偏好按桌面隔离，属于浏览器本地数据。

旧首页内容自动迁入管理员桌面，旧图标和背景在迁移时复制且保持引用；GateHome 配置随后只保留开关和端口。完整加密备份包含所有已保存的用户桌面和引用的图片，也包含 Page 账号的密码哈希。恢复时验证每个用户的配置与图片，拒绝缺失文件、路径穿越和不受支持的目录。旧版备份会迁移为管理员桌面；旧的部分备份保持原有的文件保留行为。

新目录的恢复与回滚需要新版启动器。Linux 使用 0.0.34 或更新版本安装脚本更新安装，保留原有三个目录；Docker 保留挂载目录后更新镜像。业务程序发现旧启动器时会阻止无法完整保护 Page 数据的维护操作，并给出升级提示。仅通过网页更新业务程序不会更新不可变启动器。
