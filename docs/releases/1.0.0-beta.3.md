# GateHome v1.0.0-beta.3 测试版

针对真实线上环境多场景反馈的交互与视觉问题，对表单控件基线、滑动开关布局、导航栏下拉层叠、侧边栏文本溢出以及日志查询筛选体系进行了深度专项优化与对齐修复。

- **下拉选择器与文本输入框垂直对齐修复**：
  - 移除了导致 WebKit/Blink 引擎文本基线整体下移的 `line-height: 36px` 属性，统一全局输入框与下拉选择框为 `height: 38px !important; line-height: normal !important; box-sizing: border-box !important`。
  - 彻底解决反代路由弹窗中「所属反代组」、「防火墙」下拉菜单，以及设置页「代理密码」选择器等处文字下半部分被容器边框截断的问题。
- **开关控件（Toggle Switch）与弹窗标签排版规范重构**：
  - 修复了配置弹窗中开关控件变为多行大灰块的异常。将 `.toggle-row` 重构为透明横向弹性行（`flex-direction: row; justify-content: space-between; background: transparent; border: none;`）。
  - 精确隔离全局弹窗 `dialog label` 选择器，排除 `.toggle-row`、`.check-row` 等控件，防止将横排开关强行拆散为竖向堆叠。
  - 精确校准开关内部滑块圆点位置，确保在深浅模式下均居中且动画流畅。
- **用户操作面板背景穿透修复**：
  - 规范补齐全局 CSS 变量 `--popover-bg` 与 `--modal-bg`（深色 `#111827`，浅色 `#ffffff`）。
  - 为顶部导航栏管理员头像下拉菜单（`.user-dropdown-popover`）配置实体不透明背景与最高层级（`z-index: 1000`），彻底消除浅色模式下底层按钮（如「重新读取」）穿透菜单显示的视觉干扰。
- **侧边栏网关信息排布优化**：
  - 优化侧边栏底部管理地址容器，开启单行文本截断与省略号（`text-overflow: ellipsis`），防止长域名导致布局挤压。
  - 「退出登录」操作按钮强制单行不换行（`white-space: nowrap`），避免出现「退出登\n录」换行割裂。
- **日志与防火墙记录模块空间紧凑化与单行筛选重构**：
  - 精简页面顶栏高度，将日志类型切换（「反代访问日志」/「项目系统日志」）作为药丸式分段器放置在顶栏右侧，充分利用右侧空闲区域。
  - 将原本平铺占满屏幕的多行筛选项升级为 **常用单行核心筛选 + 可折叠高级筛选抽屉**：
    - 主筛选行集成常用核心字段（反代规则/项目分类、执行结果、关键词检索）与操作按钮组（筛选、高级抽屉开关、重置、刷新）。
    - 来源 IP、请求方法、HTTP 状态码、起止时间及安全策略/引擎/动作等次要筛选维度收容至滑动抽屉内，按需展开。
    - 抽屉折叠时自动统计并显示已生效的高级筛选条件数量徽标（如 `(2)`），兼顾整洁与即时感知。

## 安装与更新

这是 GitHub **Pre-release** 预发行版本，支持在线一键更新与离线包更新：

1. **在线更新**：在现有 GateHome 控制台进入「更新」页面，更新渠道选择「Beta 测试版」，点击「检查新版本」，检测到 `v1.0.0-beta.3` 后点击「更新到此版本」，系统将自动执行在线拉取、备份与重启更新。
2. **离线更新**：在「更新」页面直接上传 `gatehouse-1.0.0-beta.3-update.zip`，校验 SHA-256 签名后完成服务热更新。

| 附件 | 用途 |
| --- | --- |
| `gatehome-linux-amd64.tar.gz` | Linux x86_64 完整安装包，包含启动器脚本及 systemd 注册配置 |
| `gatehome-linux-arm64.tar.gz` | Linux ARM64 完整安装包 |
| `gatehouse-1.0.0-beta.3-update.zip` | 网页端与控制台在线更新包，跨平台通用 |
| `gatehome-SHA256SUMS` | 安装包 SHA-256 完整校验清单 |

升级前建议备份 `config`、`log`、`data`、`sunpanel` 目录。现有数据平滑兼容，无需执行 `init`。
