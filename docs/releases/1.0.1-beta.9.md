# GateHome 1.0.1-beta.9

- 左侧「观察与管理 → 通知中心」和顶栏铃铛均可打开通知记录。支持按已读、未读和分类筛选，查看详情、标为已读或删除记录。
- 服务端保留最近 60 条故障与恢复记录，浏览器关闭期间也会记录。阅读状态保存在当前浏览器。
- 在「故障推送」中可分别为 Webhook 和 WxPusher 选择反代上游连续失败、WebDAV 备份失败及正式证书即将到期。已有 Webhook 配置升级后默认保留全部三类订阅。
- 反代连续两次检测失败后，每个已订阅渠道生成一条故障通知，持续超时期间不会重复生成，恢复后再通知一次。

在管理台「更新」中选择「Beta 测试版」渠道即可检查更新。
