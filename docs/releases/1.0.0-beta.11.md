# GateHome 1.0.0-beta.11

修复统一日志脱敏遗漏、限速计数的过期回收和超大请求体的检测覆盖；新增 MCP 首页/安全策略权限及可信前置代理设置，改善备份期间反馈和移动端表单。

## 安全与网关

- GitHub/WebDAV/备份加密密码加入落盘前脱敏，保持现有网络错误的安全反馈。
- 满载计数及时回收过期槽位，扫描节流；保留未过期状态与限速保护。
- WAF 仅记录模式对超限正文检查可用前缀，同时提示检查不完整，完整正文仍回源；拦截模式仍返回 413。
- 可信代理只接受显式配置的 IP/CIDR，从转发链右侧识别客户端；默认仍使用实际连接 IP。
- 非法上游重载返回错误并保留原路由；会话满载优先淘汰最早到期项。

## AI 与运维

- 首页修改与网关修改可分别授权；安全策略权限控制防火墙、管理来源、可信代理和 IP 冻结操作。旧 Token 保留原有授权，旧客户端保存不会丢失新增限制。
- 未绑定客户端继续禁止继承全局首页账号；维护权限仍单独控制重启、更新与恢复。
- DDNS 每批最多并发 4 组，合并重复触发；证书连续失败按 5 分钟、15 分钟、1 小时退避。
- 首页启动或备份时及时反馈重试，保持完整快照和进程生命周期的互斥。

## 控制台

- 合并共享状态轮询，限制慢请求重叠，后台暂停、回到前台刷新。
- Toast 支持安全区、长文本和高度限制；普通表单字段改用显式样式，权限卡片保持单复选框。
- 修正图片格式提示，增加表格横向滚动阴影与键盘入口，验证 320/390px 编辑器。

配置、SQLite 和原账户继续沿用。新增权限限制由新版程序执行，手动降级前应停用受限 Token；管理入口仍需独立主机名和 HTTPS。完整核验、兼容说明与测试范围见 [修复验收记录](../audit-remediation-2026-11-10.md)。

当前为 develop 候选构建，尚未创建 GitHub 发行版。本机实例已通过原更新流程运行 beta.11，原账户与业务数据保留。
