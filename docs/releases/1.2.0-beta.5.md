# GateHome 1.2.0-beta.5

- **GeoIP 数据库 (`country.mmdb`) 镜像预下载与管理**：在「端口与核心」新增 GeoIP 数据库管理卡片，支持从多 CDN 镜像源（`fastly.jsdelivr.net` / `testingcf.jsdelivr.net` / `cdn.jsdelivr.net` / GitHub）在线下载以及**手动上传 `country.mmdb`** 兜底；点击启动 Mihomo 前若检测到 `country.mmdb` 缺失或损坏会自动清理并尝试镜像预下载。
- **修复首次启动控制接口未就绪问题**：将启动就绪检测超时从 5 秒放宽至 60 秒并保留 500 条运行日志缓冲，避免首次下载 GeoIP 数据库期间误杀进程导致反复报错 `19090 connection refused`。
- **新增「运行日志」独立页签**：位于「配置文件」之后，支持关键字筛选、按级别着色展示、手动刷新、2 秒实时自动刷新与一键清理日志。

可在管理台「更新」页面选择「Beta 测试版」检查更新。
