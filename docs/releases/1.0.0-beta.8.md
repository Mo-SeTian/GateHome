# GateHome 1.0.0-beta.8

GateHome 1.0.0-beta.8 重点针对移动端与桌面端的界面栅格平衡与微交互进行了深度优化，彻底重构了「反代路由图片选择器」与「AI 管理·MCP 权限开关卡片网格」，实现像素级严格对称与高质感视觉统一。

## 🌟 核心改进与修复说明

### 1. 反向代理路由图片选择器：两端严格对齐与满宽栅格重构
- **消除右侧大片留白与错位断层**：
  - **第一通道（本地上传）**：左侧为 `40×40px` 圆角预览槽，右侧为自适应填满剩余全部空间的【选择本地图片】高质感渐变按钮（`flex: 1`）；在已上传图片时，右侧紧贴高辨识度【恢复默认】按钮，两端起止位置与卡片边界 100% 严丝合缝。
  - **第二通道（在线导入）**：左侧为 100% 满宽在线图片地址输入框（内嵌 Link 图标与软阴影），右侧紧跟【导入】操作按钮。
  - **像素级测量对齐**：移动端（375px ~ 430px）和桌面端经真实渲染测量，第一行与第二行的左边缘、右边缘水平位置绝对一致（误差为 0px），彻底消除错位断层感。
  - **格式说明居中规整**：将格式支持小字独立收敛至卡片底部，结构层次分明。

### 2. AI 管理·MCP 权限开关：重构为 2×2 对称微光网格卡片
- **根治复选框悬空与文字参差错位**：
  - 彻底清除全局 `dialog label` 纵向流对权限复选框的样式污染，不再出现复选框在上面悬空晃动、文字在下面字数长短不一的割裂现象。
  - 采用响应式网格设计：桌面端 4 列等分平铺，移动端（$\le 640\text{px}$）自适应为严格等宽的 2×2 卡片网格（宽度与列间距 1:1 对称）。
- **高质感交互卡片设计**：
  - 每个权限选项升级为独立点击卡片，左侧配有精致的勾选指示器（未选时深色微亮微边，勾选激活时呈现品牌蓝紫微光与白色对勾），右侧为权限文字。
  - 保留标准可访问性原生输入控件，完全兼容键盘交互与无障碍屏幕阅读器。
