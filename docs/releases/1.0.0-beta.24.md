# GateHome 1.0.0-beta.24

- 支持 GateHome 与 SunPanel 使用独立域名：两边分别登录后，在批量联动或单个网站导入中点击“连接 GateHome”，通过管理会话读取反代并自动返回 SunPanel；会话过期时先登录再继续。
- 同域和原生独立端口继续使用已有会话直接读取。跨域连接不共享管理 Cookie，不传输密码或 Token，只返回已启用反代的名称、分组及内外网地址。
- 接收来源限定为首页设置中的 SunPanel 访问地址或指向本机首页端口的已启用反代；管理入口沿用设置中的公网访问地址。多个管理入口可选择，地址未配置时提供明确提示。
- 连接窗口兼容手机端，支持弹窗被拦截、用户取消、超时、关闭弹窗及账号切换后的清理；连接完成前不把未读取的来源误判为已停用。
- 补充双会话与来源边界、消息来源与请求匹配、原有同域入口和真实浏览器跨域导入回归，并将 SunPanel 联动单测及类型检查加入发布检查。
