# GateHome 1.2.0-beta.1

- 新增内置独立托管「代理分流（Mihomo）」模块：面向局域网代理与分流管理，内核作为受管隔离进程运行，控制面经 GateHome 管理认证代理访问。
- 支持三组独立可自定义代理端口（Mixed HTTP+SOCKS5、HTTP/HTTPS、SOCKS5，填 0 可单独停用）与跨模块端口冲突检查，并支持局域网地址一键复制。
- 新增 5 层配置合成流水线：无订阅冷启动最小基线、机场源配置保留（`source.yaml`）、GateHome 核心覆盖（三端口 / `allow-lan` / `IPv6` / DNS 增强模式 / 日志级别）、自定义策略组（手选与正则筛选）与置顶自定义分流规则，最终生成 `runtime.yaml` 并支持在线直改与一键重合成。
- 支持 3 级出站代理接管策略：启用「GateHome 出站自动使用此代理」且内核运行中优先走本地 Mihomo，否则回退系统设置手动代理或直连，并在系统设置页展示接管状态联动。
- 新增「代理分流」原生浅/深色自适应管理界面、内核在线下载（MetaCubeX/mihomo 官方发行包）与本地上传（`.gz`/二进制校验安装）。

可在管理台「更新」页面选择「Beta 测试版」检查更新。
