# GateHome 1.0.1-beta.7

- 设置新增「入口暴露总览」，集中显示管理台、SunPanel、反代和端口转发的运行监听、TLS、登录和防火墙。SunPanel 的独立端口、内嵌入口和本机反代分别显示。
- 管理员可以在「通行密钥与会话」注册 Passkey、查看登录设备和最近活动，并逐个撤销会话。Passkey 支持 HTTPS 管理域名及 localhost，原有密码也可继续登录。
- 查看已保存凭据时可复用最近 5 分钟内的身份验证。过期后点击小眼睛即可使用密码或 Passkey 验证并继续。
- SunPanel 移除固定初始密码。首次启用，以及升级后仍使用旧出厂密码的账号，需要在 GateHome 的「浏览器首页」设置新密码。已有书签和桌面会保留。
- SunPanel 自定义页脚只显示文字和安全 HTTP(S) 链接。普通 API 增加请求体大小上限，图片及便携备份上传沿用各自的限额。

本版本为预发行版。可在管理台「更新」中选择「Beta 测试版」渠道检查更新。
