# GateHome v1.0.0-beta.4 测试版

针对移动端深度交互、文件上传控件质感、概览页拖拽排版以及全站折叠展开交互展开系统性深度优化与视觉重构。

- **移动端日志与通用筛选栏错位全面调整**：
  - 彻底重构移动端（≤768px）下日志查询栏布局：主筛选维度升级为 2 列等宽对称网格（反代规则/项目分类与执行结果各占 50%），关键词检索自适应全宽占据次行。
  - 筛选、高级折叠、重置与刷新操作按钮组优化为全宽紧凑排列，彻底消除移动端小屏幕（≤400px）下按钮折叠下坠或截断错位。
  - 高级筛选抽屉在移动端弹性降级为整洁单列流，消除 `datetime-local` 时间控件在窄屏下的横向溢出；移动端分页控制器结构化居中对齐。
- **概览页仪表盘自适应排版与卡片等高优化**：
  - 在概览 Bento 网格中引入 `grid-auto-flow: dense;` 智能紧凑流排版机制，彻底消除因手动拖拽排序混合长款双列与单列组件时出现的布局空洞与错落不齐。
  - 组件卡片统一应用 `height: 100%` 弹性延展，底部时间提示、运行信息与网络统计利用边缘粘滞（`margin-top: auto`）在同排卡片间完美基线对齐。
- **点按展开小组（`<details>` / `<summary>`）UI 规范重构**：
  - 移除浏览器默认的简陋黑色三角形折叠框，全站统一接入 Aurora 毛玻璃与微光交互规范。
  - `<summary>` 统一升级为整洁触控行，右侧内嵌带有 0.25s 极光滑动旋转动画的微光 Chevron 箭头（展开时平滑旋转 180°）。
  - 针对动态域名「关联 N 个反代组」、IP 订阅「引用防火墙策略」以及端口转发「活跃监听」等展开内容，全部重构为精致的流式微光胶囊标签组（`.ref-pill`），视觉与信息层级清晰明了。
- **文件上传选择器（`<input type="file">`）全套定制重构**：
  - 全局美化原生 `input[type="file"]`，移除浏览器默认灰白矩形按钮，定制为带有微光高光与悬浮动效的极光渐变按钮（`::file-selector-button` / `::-webkit-file-upload-button`）。
  - 路由新建/编辑弹窗中的「服务图片」选择器全面升级为集成面板：支持 48×48 圆角图标实时预览、本地图片一键选取、在线 URL 快速导入与默认图标一键恢复。
  - 系统更新页与备份还原页新增选中文件的即时回显胶囊标签（`.selected-file-pill`）。

## 安装与更新

这是 GitHub **Pre-release** 预发行版本，支持在控制台内一键在线热更新：

1. **在线更新**：在现有 GateHome 控制台进入「更新」页面，更新渠道切换为 **Beta 测试版**，点击「检查新版本」，检测到 `v1.0.0-beta.4` 后点击「更新到此版本」，网关将自动执行无损热升级、备份与平滑重启。
2. **离线更新**：在「更新」页面上传 `gatehouse-1.0.0-beta.4-update.zip`，验证 SHA-256 签名后完成服务更新。

| 附件 | 用途 |
| --- | --- |
| `gatehome-linux-amd64.tar.gz` | Linux x86_64 完整安装包，包含启动器脚本及 systemd 注册配置 |
| `gatehome-linux-arm64.tar.gz` | Linux ARM64 完整安装包 |
| `gatehouse-1.0.0-beta.4-update.zip` | 网页端与控制台在线更新包，跨平台通用 |
| `gatehome-SHA256SUMS` | 安装包 SHA-256 完整校验清单 |

升级前建议备份 `config`、`log`、`data`、`sunpanel` 目录。现有数据平滑兼容，无需执行 `init`。
