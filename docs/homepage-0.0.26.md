# GateHomePage

进入 GateHome 管理界面的“浏览器首页”，在“桌面设置”开启功能并填写独立端口。默认端口 16680，端口须为 1024–65535，开启时不能与管理端口或任何反代监听端口重复。启停和端口变更后重启 GateHome；关闭后原有链接和设置保留。内容、布局、图片和 CSS 保存后，刷新首页即可查看。

“编辑桌面”显示添加分组、页面、链接和导入工具，再点“完成编辑”收起。独立首页右上角的“编辑桌面”打开管理界面的首页配置；公网管理域名已配置时跳转到该地址，否则使用当前主机的管理端口。

首页只显示一层分组标题栏：分组名称位于应用卡片上方左侧，右侧显示当前组的链接总数。分组较多时横向滚动选择；组内页面继续通过圆点切换。

每组至少一个页面。页面设置包含行数、桌面列数及手机端最多列数。每个圆点页的容量为行数乘实际列数；屏幕变窄会减少实际列数，超出容量自动生成续页。链接保持完整，可通过圆点、键盘左右键或横向滑动翻页。浏览器记住每组的当前页和内外网选择。

网页搜索在“桌面设置 → 搜索引擎”配置，可添加、修改和移除 1–12 个引擎，默认预置百度与 Google。搜索地址须为不含账号密码的 HTTP / HTTPS 地址，并在路径或查询参数中填写一次 `{query}`，例如 `https://www.baidu.com/s?wd={query}`、`https://www.google.com/search?q={query}`。点击首页搜索框左侧的图标按钮选择引擎，按回车或点击搜索按钮，在新标签页打开结果；关键词会自动编码。首次使用默认第一项，浏览器记住自己的选择；移除选中的引擎后切回第一项。引擎名称、地址和自定义图标随配置保存并进入备份，关键词不保存。

百度与 Google 使用本地矢量图标；其他引擎默认显示通用网站图标。在每个搜索引擎的“自定义图标”中上传图片或通过 URL 获取图标，支持与链接图片相同的格式和大小限制；点击“恢复默认图标”移除自定义图片。首页的图标按钮提供引擎名称提示、无障碍标签与选中状态，选择面板支持 Tab、回车和 Escape。

链接至少填写内网、外网地址中的一项，只支持不含账号密码的 HTTP / HTTPS URL。缺少当前网络地址时，卡片提示未设置，不会自动跳转到另一种网络。编辑链接的“所属页面”可跨分组移动链接；置顶项先展示，其余按管理列表顺序排列。反代导入是一次性复制，不会覆盖后续手动编辑。重复导入时跳过目标页面中内外网地址均相同的条目。

链接图片支持 PNG、JPEG、GIF、WebP、ICO，上传和 URL 下载上限 5 MiB。位图重新编码到最长 128 像素，移除元数据；ICO 最大 64 KiB。背景支持 PNG、JPEG、GIF、WebP，最长 4096 像素，下载上限 5 MiB；转为最长 2560 像素、最大 2 MiB 的 JPEG。GIF 使用首帧。URL 由服务器下载并缓存，支持内网应用图标；无效 HTTPS 证书和元数据地址会被拒绝。尚未保存到配置的上传图片不进入备份，闲置超过一天后在后续保存或上传时清理。

自定义 CSS 最多 32 KiB，作为独立样式文件加载，不插入 HTML，也不影响 GateHome 管理页。可调整稳定的页面类名：

```css
.gh-main { max-width: 1200px; }
.gh-link-grid { --gh-gap: 20px; }
.gh-item { border-radius: 24px; }
.gh-art { width: 56px; height: 56px; }
@media (max-width: 700px) {
  .gh-main { padding-inline: 14px; }
  .gh-link-grid { --gh-gap: 10px; }
}
```

自定义 CSS 在内置样式之后加载。首页限制外部脚本、字体、图片和 CSS 网络请求；自定义背景与图标须使用上传或 URL 导入。CSS 可能覆盖响应式布局，修改后请自行检查手机效果；清空自定义 CSS 即可恢复内置布局。系统“减少动态效果”开启时，翻页立即完成并取消卡片位移动画。

访问方式可选“允许访客查看”或“管理员登录后查看”。允许访客时，选定的链接名称和内外网地址可被访客读取；不会公开管理配置、凭据或未选用的反代图片。登录模式使用 GateHome 管理员账号验证，发放独立首页 Cookie 和会话，不能用于管理 API；修改管理员账户会同时使这些会话失效。每个反代服务的访问账号继续独立管理。

配置（分组、页面、链接、行列、CSS）写入 `/config/state.json`，图标写入 `/data/route-images`，背景写入 `/data/homepage-backgrounds`。加密备份包含全部已保存引用的图片；完整恢复会还原这些目录，缺失或损坏图片拒绝恢复。保留 Linux 或 Docker 的 `/config`、`/log`、`/data` 三个目录即可在重新安装后保留全部数据。浏览器的当前分组、页码和网络选择属于本地浏览偏好，不在服务器备份中。

Docker bridge 需另外发布首页端口，Linux host 网络直接使用监听端口。独立首页提供 HTTP，公网可以通过自己的 HTTPS 反代域名访问；反代上游填写 `http://服务器IP:16680`，以实际设置替换端口。

首次从旧版本升级使用首页图片时，请用 0.0.27 或更新版本的安装脚本重新安装一次，保留原有三个数据目录；Docker 保留挂载目录后更新镜像。网页更新只替换业务程序，旧启动器可能在回滚时漏掉仅首页使用的图标。新版会检查启动器能力，发现不兼容时拒绝恢复、在线更新应用及维护重启，并提示升级方式。下载加密备份和首页查看不受影响。

内置百度图标路径来自 [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/baidu.svg)（CC0-1.0）；百度与 Google 标识分别属于其商标持有人，用于标识搜索引擎。
