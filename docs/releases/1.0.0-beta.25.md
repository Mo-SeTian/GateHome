# GateHome 1.0.0-beta.25

- SunPanel 批量导入与单个网站导入可同时带入 GateHome 的图标库及上传图片，支持独立域名联动。
- 图片在已登录的 GateHome 连接中读取，转换为保留完整比例和透明背景的 PNG 图标，再保存到当前 SunPanel 账号的本地上传目录；显示不再依赖 GateHome 登录状态。
- 关联更新可补齐旧书签的空白图标，并按需更新之前带入的图片；SunPanel 自定义图标及主动清空的图标保持不变。来源图片无法读取时提供提示并保留已有图标。
- 首页导出、导入及备份保留图片和关联信息，兼容旧版及 MCP 不含图片字段的请求。
- 增加图片读取鉴权、路径安全、来源校验、关联更新、便携导入导出和真实浏览器像素与显示回归；Docker 构建同步包含两套前端共用的图片处理模块。
