# GateHome 1.2.0-beta.10

- **代理分流（Mihomo）安全与稳定性全面加固**：
  - 将 `rule-providers.path` 严格限定在 `./ruleset/` 子目录并校对文件扩展名与符号链接逃逸，防止配置文件读取、覆盖与跨目录写入；手动 YAML/校验亦同步限制 `rule-providers` 与 `proxy-providers` 路径。
  - 扩大 `custom.yaml` 及合并层托管保护键（新增 `skip-auth-prefixes`、`external-controller-tls`/`-unix`/`-pipe`/`-cors`、`external-ui*` 与端口/局域网设置），`DNSListenPort == 0` 时主动清除订阅自带的 `dns.listen`，上传内核前校对 ELF/Mach-O/PE 可执行文件魔数。
  - 对订阅下载错误中的 URL/Token 进行脱敏；为控制端反向代理禁用环境变量代理并增加变更与 WebSocket 来源校验；为 `Start`/`Stop`/`Restart`/上传安装引入生命周期串行锁，改用持久化共享 HTTP Transport 与无行长限制的日志管道读取。
- **网关防护、认证与出站 SSRF 加固**：
  - 修复 WAF 例外规则（`REQUEST_FILENAME` + `t:normalisePath` + 段边界）、路径限速与自定义规则的路径归一化绕过，拒绝含 `..` 路径段的代理转发，清理非受信任来源伪造的 `X-Forwarded-For`/`Forwarded` 头，并以最右侧 `X-Forwarded-Proto` 判定 HTTPS。
  - 修复未认证登录慢速体占用全局并发槽位问题；闭合 MCP `security_write: false` 对 `subscriptions`、`outbound_proxy` 与受保护路由安全策略的越权修改；修改管理员账号/密码时同步失效进行中的 Passkey 挑战流；补齐日志与 MCP 脱敏列表中的助手 API 密钥。
  - 为系统出站代理、AI 助手（单次 DNS 解析 + 代理内网端口校验）与独立端口 SunPanel 站点探活补全元数据及 GateHome 内部端口 SSRF 防护；消除 WireGuard TCP 中继、健康检查事件通知、Mihomo 状态快照及 IP 防御热路径上的锁竞争与数据竞争。
- **前端可靠性与构建发布安全升级**：
  - 修复 Mihomo「连接」页首屏请求自中止及 YAML 多文件切换异步乱序问题；退出登录时清除本地助手历史；为 Storage 读取增加容错与非 GET/HEAD 请求 CSRF 头兜底；增加组件卸载中止清理与后台标签页自动暂停轮询。
  - GitHub Actions 发布流水线按最小权限原则拆分为只读 `build-and-verify` 与受限 `publish` 任务，并补齐 SunPanel 全部 Go 与 JS 测试覆盖。

可在管理台「更新」页面选择「Beta 测试版」检查更新。
