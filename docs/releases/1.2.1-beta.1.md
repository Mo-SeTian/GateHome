# GateHome 1.2.1-beta.1

- **多 DNS 服务商支持（DDNS + ACME DNS-01 SSL 证书）**：
  - 在原有 Cloudflare 基础上新增 **阿里云 DNS**、**腾讯云 DNS (DNSPod)**、**华为云 DNS** 与 **Porkbun**，全面支持 DDNS 同步与 Let's Encrypt DNS-01 证书签发（纯标准库实现，沿用出站代理与 Mihomo 接管链路）。
  - 升级双密钥凭据隔离存储、分字段按需查看（`AccessKey ID / Secret` 等）及全链路日志脱敏，保持原有 Cloudflare 配置与接口 100% 兼容。
- **拓展通知推送（多渠道模板 + 6 类告警事件）**：
  - Webhook 新增 7 种原生推送模板：**通用 JSON POST**（可选 HMAC 签名）、**企业微信群机器人**、**飞书 / Lark**（支持签名校验）、**钉钉群机器人**（支持关键字与 `SEC` 加签）、**Telegram Bot**、**Bark** 与 **Gotify**。
  - 告警事件在原有反代上游、WebDAV 备份、证书到期基础上，新增可选订阅 **DDNS 同步失败/恢复**、**Mihomo 核心退出与订阅异常/到期/余量预警**、**安全防护与登录限流冻结**（带 5 分钟合并去重冷却）。
- **Mihomo 订阅定时自动更新与预警联动**：
  - 为远程订阅新增定时自动更新周期（关闭 / 6h / 12h / 24h / 3 天 / 7 天），后台按周期自动拉取并支持 15 分钟失败退避；若新订阅与当前配置合成失败，自动回滚保留原订阅与运行配置。
  - 新增订阅到期（≤ 3 天）与流量余量（≤ 10%）状态徽章与通知中心预警联动。

可在管理台「更新」页面选择「Beta 测试版」检查更新。
