FIREWALL

添加防火墙

从上到下匹配，第一条命中决定允许或禁止。“包含”匹配组内 IP，“排除”匹配组外 IP。手动 IP 与勾选订阅合并为该组。仅使用 Web 防护时，将 IP 未命中动作设为允许。

任一引用的订阅尚无有效缓存时，该防火墙暂时拒绝所有访问；更新失败保留上次成功列表。保存时校验规则，成功后立即生效；校验失败保留原策略。

Web 攻击防护

Coraza 3.8.1 · OWASP CRS 4.25.0。建议先仅记录，确认误报后开启拦截。IP 允许不会跳过以下防护。

拦截模式超限返回 413；仅记录模式超限记录“未完成检查”并转发。上传服务请调整上限。响应内容及 WebSocket 消息不检查。

规则例外

仅豁免指定 CRS 规则。域名留空作用于本防火墙所有服务；路径按前缀匹配，参数留空豁免该请求的整条规则。

爬虫与自定义 HTTP 规则

按顺序匹配 User-Agent、路径或请求方法的正则表达式，支持 (?i) 忽略大小写。拒绝规则立即拦截；仅记录规则继续检查。修改 UA 可绕过 UA 规则，建议结合限速。

访问频率限制

超限返回 429 和重试时间；按实际连接 IP 计算，不信任客户端伪造的转发头。前置代理会影响看到的来源地址。

防护触发自动冻结

WAF、HTTP 规则、限速分别累计，一次请求只记一次。仅记录命中和请求体超限不会自动冻结。与独立账号的失败计数分开，在同一冻结名单管理。
