# GateHome 1.2.0-beta.3

- **页签独立拆分**：将「订阅管理」（机场订阅与专线 DNS 策略）与「端口与核心」（代理端口、局域网认证、Zashboard 面板与 Mihomo 内核）拆分为独立功能页。
- **Zashboard 面板集成与一键打开**：支持一键打开与在线下载官方 Zashboard 面板，由 GateHome 现有管理会话托管静态界面并反代 `/api/mihomo/ctrl/*`（HTTP + WebSocket），无需暴露 `127.0.0.1` 控制端口或 `secret`。
- **局域网代理账号密码认证**：支持为局域网接入配置代理账号密码（`authentication`），自动写入本机 `127.0.0.1` 回环免密（`skip-auth-prefixes`）保障出站联动，并对状态接口与 YAML 视图自动脱敏回填。
- **订阅节点筛选与统一后缀**：支持添加和编辑订阅时设置正则保留、正则排除与节点统一后缀，自动同步更新 `proxy-groups` 成员，同时保持 `source.yaml` 原件无损。
- **策略组编辑与规则排序**：支持编辑已创建的自定义策略组，以及通过上/下按钮调整自定义分流规则的匹配优先级。
- **策略组测速与切换修复**：改为请求体传参解决含 `/` 与 Emoji 组名的路由问题，补充单节点并发测速兜底与超时标记，测速时自动展开节点列表并提示结果。
- **配置文件编辑器增强与校验门控**：支持语法高亮与行号预览、`source.yaml` 只读高亮、全屏与自动换行切换、一键格式化，以及修改后强制校验（语法、策略组引用与 `mihomo -t` 内核测试）通过才可保存热重载。

可在管理台「更新」页面选择「Beta 测试版」检查更新。
